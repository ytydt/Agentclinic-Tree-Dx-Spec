\section{Glossary of Terms and Repository Codes}
\label{app:glossary}

\begin{description}
  \item[APHHM.] Alignment-Preserving Hierarchical Hypothesis Management; the framing of this paper.
  \item[Recall--Discrimination Dilemma.] Increasing recall admits correct diseases but also redundant/similar candidates that harden discrimination; retained as motivation, upgraded by alignment requirements.
  \item[L1 / L2.] Level-1 family / Level-2 concrete disease leaf.
  \item[RRF.] Reciprocal Rank Fusion~\cite{rrf2009}.
  \item[Anti-anchor.] Candidate-relative evidence selector that resists headline prototype bias; open hypothesis in this draft.
  \item[Soft prior.] Overturnable L1 score used in global arbitration.
  \item[Belief state.] Shared tree carrying identities, membership, and posteriors for later stages.
  \item[A1 / A2 / A3.] Representation, state, and interface alignment invariants (Section~\ref{sec:dilemma}).
  \item[Fine crowding.] Near-synonym leaves occupy multiple top frontier slots, so a $k$-slot budget covers fewer than $k$ canonical concepts.
  \item[Quotient / canonical concept space.] The set $L/\!\sim$ of clinical equivalence classes; competition should be scored there rather than over raw label strings.
  \item[open-MRR@$k$.] Reciprocal rank of the first delivered diagnosis judged correct among the top $k$, $0$ if none. A ranking metric over \emph{delivered diagnoses}; distinct from reasoning recall (RR), which measures coverage of reasoning facts. The two are not comparable.
  \item[any-hit@$k$.] Whether any of the top-$k$ delivered diagnoses is judged correct.
  \item[Count-matched semantics-blind merge.] Control operator with the deployed gate, class count and class-size profile, but randomized class membership; isolates equivalence semantics from candidate-count reduction (\Cref{sec:res-eq}).
  \item[Endpoint admissibility / algebraic identity.] An endpoint is inadmissible for a module if its per-case value is constant under randomized perturbation of that module, i.e.\ null variance exactly $0$. Such endpoints yield $p$-values that carry no information.
  \item[Selector abstention cascade.] Non-case-adaptive L1 axis $\rightarrow$ candidate-relative selector abstains ($n_{\mathrm{sel}}{=}0$) $\rightarrow$ empty ranking $\rightarrow$ mapper miss (\Cref{sec:res-org}).
  \item[\texttt{structural\_reach}.] Gold present anywhere in the tree before ranking; a coverage process metric, not end-task @1.
  \item[Factorial decomposition.] Crossing factors (e.g.\ budget${\times}$write-back) so main effects are not read off a confounded joint contrast (\Cref{sec:res-state}).
  \item[Gap-fill.] One-shot non-reducing L1 repair when a high-ranked recalled disease has no parent; not claimed as a major end-to-end recall win here.
  \item[compat\_parallel.] Heuristic exclusive merge-vs-calibrate compressor behind FineCrowdGate.
  \item[FineCrowdGate.] Gold-blind detector of synonym crowding among top-ranked leaves.
  \item[Live posterior write-back.] Writing local evidence posteriors into the shared tree before global decoding.
  \item[Bounded frontier / posterior pool.] Uncertainty-aware multi-leaf submission or Top-$N$ closed decoding set.
  \item[closed\_live\_mac\_supervisor.] Closed-pool multi-doctor + supervisor shortlist used on OX.
  \item[B02-SC10.] Flat retrieve--rerank control with ten self-consistent trajectories fused by reciprocal rank ($\approx 90$ model calls per case); the budget-matched baseline used in Section~\ref{sec:rq4}.
  \item[Synonym bind-repair / Approach~A.] Offline repair of empty option--leaf bindings at the scoring interface. Diagnosed in Section~\ref{sec:protocol} but \emph{excluded from all reported results}, because it raises baseline scores at least as much as ours.
  \item[\texttt{TREE\_PARENT\_ABSENT}.] No acceptable L1 parent for the gold disease.
  \item[\texttt{L2\_MISS}.] Parent exists but no gold-equivalent L2 leaf in the tree universe.
  \item[\texttt{LOCAL\_ELIMINATION}.] Leaf exists in-family but is dropped before global decoding.
  \item[\texttt{GLOBAL\_MISRANK}.] Leaf enters the global pool but ranks too low.
  \item[\texttt{MAPPER\_UNBIND}.] Leaf present/rank-sufficient, but evaluation binding is empty.
  \item[F2 / F4 / F6.] Evidence prefix lengths in logs; implementation detail only.
  \item[Config~A.] Branch-conditioned L2 generation recipe; implementation detail.
  \item[Interp.\ Acc / IAcc.] OX interpretation accuracy under LLM judge template \texttt{ox.interpretation\_consistency}.
\end{description}

\section{Compression Variants: Equivalence Bounds}
\label{app:eq-equiv}

This appendix reports every pre-registered variant of the equivalence-compression operator (\Cref{sec:res-eq}), including those that produce no difference.
We report them as equivalences with bounds rather than as null results, for a reason specific to the paired design: the difference between two arms is bounded by $m/n$, where $m$ is the number of cases discordant \emph{on the endpoint}, so few moving cases give a narrow interval rather than a weak test.
Intervals are exact conditional McNemar intervals~\cite{mcnemar1947} (Clopper--Pearson on the discordant pairs, mapped to the difference scale) on $n=98$ commonly scored MCR cases with the frozen judge at $K{=}5$.
The pre-declared non-inferiority margin is $\pm 5$~pp, half the effect size our pre-registration treats as substantive.

\label{tab:eq-equiv}
\begin{tabular}{llcccl}
\toprule

\midrule

\noindent
AB10b and AB10c are identities at @1 by construction and are judged instead by the permutation test of \Cref{sec:res-eq}, where they are significantly worse than the deployed operator on both live endpoints ($p=0.015$).
AB08 is the one variant whose discordant cases run in both directions ($4$ for the deployed arm, $2$ against), so no unidirectional claim is available for it at any sample size.
\end{table}

\paragraph{Why any-hit@5 is an identity here.}
The deployed configuration delivers $2.20$ candidates per case on average and fewer than $K{=}5$ in $86$ of $98$ cases, so there is no padding headroom: any-hit@5 reduces to whether gold is in the surviving set.
Because merge is a deletion operator that always retains the best-ranked member of a class, none of the arms above can drop a label that matched gold, and seven of the nine have zero moving cases on this endpoint.
The identical column values across those arms are therefore the \emph{same number}, not a converging null, and no sample size changes this.
We flag it explicitly rather than tabulating it as evidence.

\paragraph{Structural identities.}
Serial composition (AB09) delivers the identical set, the identical rank-1 leaf, and zero moving cases on all three endpoints in this configuration; removing the L1 soft prior (AB20) moves one case.
Neither can produce a difference at any sample size on this slice, so we do not report them as evidence about the mechanism in either direction.
This also corrects an earlier reading of AB09 as evidence of operator interference: on the reconstructed pre-compat input the serial arm is not merely similar to exclusive routing, it is indistinguishable from it.

\paragraph{Conditional effect sizes.}
Restricted to cases where the delivered list actually differs, the deployed arm gains $+0.125$ Acc@1 over unconditional merge ($16$ cases) and $+0.107$ over frequency-matched random routing ($28$ cases).
Conditioning corrects the estimand but does \emph{not} add power---the sign test still counts only endpoint-moving cases---so we report these only alongside the full-sample intervals above.

\paragraph{Attainable resolution on this slice.}
The gate fires on $82/101$ cases, so any frequency-matched routing contrast can differ from the deployed arm on at most $2\min(82,19)=38$ cases; AB10 already reaches $28$ of them.
A sign test here needs six unidirectional moving cases for $p<0.05$, which linear extrapolation puts at $n\approx196$ for AB10, AB10b and AB11, $n\approx294$ for AB07 and AB10c, and $n\approx588$ for AB20.
Resolving predicate-level questions therefore requires either a larger slice or a slice stratified to a gate firing rate near $0.5$, where the discordance ceiling is maximal.
We state this as the cost of the next experiment rather than as a property of the mechanism.
