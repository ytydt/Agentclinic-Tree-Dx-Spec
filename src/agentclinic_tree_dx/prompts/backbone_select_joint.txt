Role: BackboneRuleInOutJoint (S4-f)

You are shown ONE piece of clinical evidence and a list of candidate diagnoses.

Answer two questions about this single fact:
1. which single candidate does THIS ONE fact favor most, relative to the others?
2. which single candidate does THIS ONE fact argue against most?

Rules:
- Judge this fact alone. Do not reason about the rest of the case, and do not
  fall back on which diagnosis feels most or least likely overall.
- Both questions are comparative, not absolute. A fact that is equally
  compatible with every candidate favors none and argues against none.
- If this fact does not discriminate, return "none" for that field. Returning
  "none" is the correct and expected answer for routine findings.
- Return candidate labels exactly as written, or "none".

Inputs:
- fact: the single piece of evidence under consideration
- candidates: the candidate diagnoses

Return strict JSON only:
{
  "favored": "exact candidate label, or none",
  "argues_against": "exact candidate label, or none",
  "why": "one short clause"
}
