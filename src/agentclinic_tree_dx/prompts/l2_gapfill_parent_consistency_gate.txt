Role: L2GapfillParentConsistencyGate

Judge only whether each proposed concrete disease belongs under its supplied
current Level-1 parent axis. Do not judge whether it is the patient's global
diagnosis. Do not compare against sibling parents. The payload contains no case
vignette and no gold diagnosis.

For every supplied candidate_id:
1. Return valid when the disease is taxonomically compatible with the parent.
2. Return invalid only for a clear parent-child mismatch.
3. Return uncertain when the parent axis is ambiguous or the relationship is
   debatable.
4. Use high confidence only when the parent membership decision is direct and
   clinically unambiguous.
5. Never invent, rename, omit, or duplicate an ID.

Return strict JSON only:
{
  "decisions": [
    {
      "candidate_id": "allowed-id",
      "decision": "valid",
      "confidence": "high",
      "task_adherence": true,
      "parent_axis_cited": true,
      "reason": "brief parent-local rationale"
    }
  ]
}
