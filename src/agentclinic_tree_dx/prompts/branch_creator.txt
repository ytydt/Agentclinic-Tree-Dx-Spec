Role: BranchCreator

Generate schema-level competing branches under the current root node.

IMPORTANT: You are creating Level-1 branches directly under the root node ONLY.
Do NOT attempt to create sub-branches within branches. Sub-branch creation is
handled by a separate SubBranchCreator module called later in the cycle.
Keep all generated branches at the same abstraction level (diagnosis-family level).

═══ MANDATORY NAMING RULE (ENFORCED) ═══
Branch labels MUST be BROAD FAMILY names, NEVER specific disease names.
FORBIDDEN labels: "Acute Myeloid Leukemia", "CML", "Pneumonia", "Crohn's Disease"
REQUIRED labels:  "Myeloid Neoplasm with Increased Blasts", "Chronic MPN",
                  "Lower Respiratory Infection", "Inflammatory Bowel Disease"

If ANY branch label is a specific disease entity rather than a family, your
output is INVALID. Test: can the label encompass 2+ distinct disease entities?
If not, broaden it.

═══ MANDATORY SINGLE-AXIS RULE — MECE (ENFORCED) ═══
Pick EXACTLY ONE classification axis (fundamentum divisionis) for the WHOLE set
of sibling branches, and derive EVERY branch from that same axis. Choose the one
most natural for this root: mechanism | anatomy | etiology | test_pathway |
urgency | severity | management_pathway.

Do NOT mix axes across siblings. The dominant cause of a non-MECE partition is
placing an ANATOMIC bucket next to a MECHANISM bucket, so a disease fits both:
  WRONG (mixed axes): ["Hepatobiliary/pancreatic", "Neoplastic", "Infectious"]
     → a pancreatic tumor fits BOTH "Hepatobiliary" (anatomy) and "Neoplastic"
       (mechanism): the branches overlap and the tree cannot separate them.
  RIGHT (single mechanism axis): ["Obstructive/structural", "Neoplastic",
       "Infectious/inflammatory", "Toxic/metabolic", "Vascular"]
  RIGHT (single anatomic axis):  ["Pre-hepatic", "Intra-hepatic", "Post-hepatic"]

Requirements for the sibling set:
- MUTUALLY EXCLUSIVE: any disease is classified into exactly ONE branch by its
  PRIMARY value on the chosen axis (no disease plausibly fits two branches).
- COLLECTIVELY EXHAUSTIVE: the branches + the residual OTHER cover the whole
  cause space of the root, so the correct diagnosis always has a reachable branch.
- PARALLEL: all siblings are values of the SAME axis at comparable granularity.
Set every branch's classification_axis field to that ONE shared axis value.

═══ MANDATORY PHASE-CROSSING RULE (ENFORCED) ═══
When blasts (≥20%) or other acute features are present AND chronic disease
families are plausible, you MUST:

1. Name the blast-bearing family by PRESENTATION PATTERN, not by a single
   disease:
     WRONG:  "Acute Myeloid Leukemia"
     RIGHT:  "Myeloid Neoplasm with Increased Blasts"
   The right label covers de novo AML AND CML blast crisis AND MDS-EB.

2. Create a SEPARATE chronic family for chronic-phase entities only:
     "Chronic Myeloproliferative Neoplasm (chronic/accelerated phase)"

3. Both families MUST be live until discriminating evidence (BCR-ABL,
   cytogenetics, bone-marrow biopsy) is available.

Mandatory haematological malignancy template (use when blasts are present):
  B1 "Myeloid Neoplasm with Increased Blasts"
     (de novo AML, CML blast crisis, MDS with excess blasts)
  B2 "Lymphoid Neoplasm with Increased Blasts"
     (ALL, lymphoblastic lymphoma)
  B3 "Chronic Myeloproliferative Neoplasm"
     (CML chronic/accelerated phase, PV, ET, PMF)
  B4 "Lymphoproliferative / Plasma Cell Disorder"
     (CLL, lymphoma, myeloma)
  B5 "Reactive / Non-malignant Leukocytosis"
     (leukemoid reaction, infection)

Instructions:
- All siblings must be at comparable abstraction levels (diagnosis-family, NOT
  mixed with specific diseases or subtypes).
- Include at least one can't-miss branch (high danger score, even if low prior
  probability) whenever the clinical context warrants it.
- Apply the branch inclusion rule: keep branch B if ANY of the following hold:
    plausibility(B) > test_threshold (0.05)
    OR danger(B) >= 0.7
    OR B uniquely explains unresolved critical evidence
- Default frontier policy: 2-4 live branches, 1-2 parked branches, optional
  residual OTHER.
- When the root node involves a process with both ACUTE and CHRONIC / SUBACUTE
  presentations, you MUST create SEPARATE branches for each major temporal
  category.
- For each branch, estimate the fields that allow the controller to score leaf
  actions:
    askable_discriminators: questions that could help separate this branch from
      competitors
    requestable_discriminators: tests or exams that could separate this branch
    turn_cost_to_refine: approximate number of turns needed to resolve this branch
    diagnosis_commitment_gain: how much confirming this branch would raise
      diagnosis readiness (0-1)
    interrupt_relevance: how urgent this branch is if confirmed (0-1)
- Annotate each branch with level_role (always "family" for Level-1 branches)
  and classification_axis (the axis used to distinguish siblings from each other).
  Valid classification_axis values: anatomy|mechanism|urgency|management_pathway|
  test_pathway|etiology|risk_context|severity|other
- External knowledge retrieval is permitted only if the diagnostic schema is
  unclear or rare.

Return strict JSON only, no markdown:
