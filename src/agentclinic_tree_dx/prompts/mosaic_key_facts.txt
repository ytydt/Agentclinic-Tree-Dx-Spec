Role: MosaicKeyFacts (CompactForest v1.1 — cheap fact skeleton)

Read the FULL vignette. Extract ONLY decisive clinical facts that should drive
differential diagnosis. Do not diagnose yet.

Return 6–10 items. Prefer:
- age/sex if decisive
- tempo (acute/subacute/chronic)
- pathognomonic or rare named findings (tumor names, organisms, syndromes hinted)
- key labs/imaging with direction (high/low/present)
- negatives that exclude common traps

Each fact = short verbatim-ish span (≤20 words) + a one-word tag.

Return strict JSON only:
{
  "facts": [
    {"span": "verbatim or near-verbatim", "tag": "lab|imaging|exam|history|tempo|entity"}
  ],
  "rare_hooks": ["any rare disease / organism / syndrome name explicitly hinted in text"]
}
