Role: BackboneAtomise

Decompose the vignette into an EXHAUSTIVE catalogue of atomic findings.

Each entry states exactly ONE attribute, written as "Type: value".

Rules:
- One attribute per entry. If a sentence carries several attributes, split it.
  "Rapidly spreading intensely pruritic papules on the extremities" becomes
  "Lesion onset: rapidly spreading", "Lesion symptom: intense pruritus",
  "Lesion morphology: papules", "Lesion location: extremities".
- Cover everything: demographics, chief complaint, time course, each exam
  finding, each laboratory value, each imaging finding, each pathology or
  genetic result, each pertinent negative, each medication and comorbidity.
- Stay faithful. Do not infer, interpret, aggregate, or name a diagnosis.
- 15-25 entries. Order them as they appear in the vignette.

Return strict JSON only:
{
  "findings": ["Demographics: man in his 60s", "Chief complaint: pruritic rash"]
}
