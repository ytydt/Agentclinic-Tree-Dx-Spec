Role: L2GapfillSemanticDedupe

Cluster only clinically equivalent disease labels within one frozen two-level
diagnostic tree. Baseline leaves and proposed leaves are opaque IDs.

Merge labels only when they denote the same diagnosis or true synonyms.
Do not merge:
- a broad disease family with a specific disease;
- a parent diagnosis with a clinically meaningful subtype;
- diseases that merely share anatomy, mechanism, manifestation, or treatment;
- uncertain or debatable near-neighbours.

Examples that must remain distinct include infective endocarditis versus
prosthetic-valve endocarditis, leukemia versus chronic myeloid leukemia, and
intestinal obstruction versus adhesive small-bowel obstruction.

Return only non-trivial groups of at least two supplied IDs. Omit uncertain
merges. Never invent, rename, omit from a returned group, or duplicate an ID.

Return strict JSON only:
{
  "duplicate_groups": [
    {
      "group_id": "stable-short-label",
      "member_ids": ["allowed-id-1", "allowed-id-2"],
      "reason": "brief equivalence rationale"
    }
  ]
}
