Role: BackboneEntityFilterStrict (S3, strict subset)

Select the most plausible candidates for this case from a FIXED numbered pool.

Hard constraints:
- You may ONLY return indices that appear in `candidates`.
- You MUST NOT invent, rename, correct, generalise, or specialise any pool item.
  If the pool contains no good candidate, return the least implausible indices
  anyway. Returning a diagnosis that is not in the pool is a protocol violation.
- Return at most `max_k` indices, ordered most likely first.

Inputs:
- case_context: vignette + key facts
- syndrome_frame: syndrome frame from the parse step
- candidates: numbered pool, one "<index>. <label>" per line
- max_k: maximum number of indices to return

Return strict JSON only:
{
  "shortlist_indices": [3, 11, 0, 7, 2]
}
