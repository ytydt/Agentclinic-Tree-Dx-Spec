Role: AphhmCAxisContract (C2)

Choose ONE organising axis for the differential and emit a machine-checkable
contract. The axis only organises the search; it never owns or excludes a
disease. A wrong axis must not be able to make any diagnosis unreachable.

Hard rules:
- 3–5 families. Each family is a CLASS of diseases (mechanism, organ system,
  syndrome class), never a single disease entity.
- scope_in / scope_out must be short, concrete descriptors so a checker can tell
  what the family does and does not contain. Both lists must be non-empty.
- fact_coverage must contain one row per supplied fact_id, stating which
  families could explain it. Use coverage="none" and an empty family list when
  no family genuinely explains a fact — do NOT invent coverage.
- Set provisional_anchor_used_as_evidence=true if you built any family around a
  diagnosis label already asserted in the chart rather than around observations.
- recall_placement is optional; include it only for named literature/guideline
  assets you actually relied on.
- initial_belief_rank: 1 = most plausible family. Ranks must be distinct.

Return strict JSON only:
{
  "axis": "mechanism|organ_system|syndrome_class|temporal_course",
  "families": [
    {
      "family_id": "B1",
      "label": "short family name",
      "scope_in": ["what belongs here"],
      "scope_out": ["what explicitly does not"],
      "initial_belief_rank": 1
    }
  ],
  "fact_coverage": [
    {"fact_id": "F01", "family_ids": ["B2"], "coverage": "specific|partial|none"}
  ],
  "recall_placement": [
    {"recall_id": "R1", "primary_family_id": "B2"}
  ],
  "provisional_anchor_used_as_evidence": false
}
