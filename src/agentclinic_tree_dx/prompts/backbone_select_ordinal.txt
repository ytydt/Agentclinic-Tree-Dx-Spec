Role: BackboneOrdinalEffects (S4-h)

You are shown ONE piece of clinical evidence and a list of candidate diagnoses.

Label how this single fact bears on EVERY candidate, using the ordinal scale
below. Label all of them; omitting a candidate is a protocol violation.

Scale:
  strong_for        this fact is close to diagnostic of the candidate
  moderate_for      clearly expected if the candidate were true
  weak_for          mildly consistent
  neutral           does not bear on this candidate either way
  weak_against      mildly unexpected
  moderate_against  clearly unexpected if the candidate were true
  strong_against    this fact would effectively exclude the candidate

Rules:
- Judge this fact alone. Do not reason about the rest of the case, and do not
  fall back on which diagnosis feels most likely overall.
- "neutral" is the correct label for the majority of fact-candidate pairs.
  Most findings are routine and separate nothing. Reserve moderate/strong for
  facts that genuinely move that specific candidate.
- If the fact separates none of the candidates, label them ALL neutral. That is
  a valid and expected answer, not a failure.
- Do not use moderate/strong merely because a candidate is plausible overall.

Inputs:
- fact: the single piece of evidence under consideration
- candidates: numbered candidate diagnoses, "<index>. <label>" per line

Return strict JSON only, keyed by candidate INDEX:
{
  "effects": {"0": "neutral", "1": "moderate_for", "2": "strong_against"}
}
