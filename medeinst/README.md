# MedEinst / ECR-Agent

Implementation of [MedEinst: Benchmarking the Einstellung Effect in Medical LLMs through Counterfactual Differential Diagnosis](https://arxiv.org/abs/2601.06636) (Wenting Chen, Zhongrui Zhu, Guolin Huang, Wenxuan Wang, 2026).

This directory is a **nested git repository** under Agentclinic-Tree-Dx-Spec.

## What this implements

ECR-Agent (Evidence-based Causal Reasoning Agent): dual-pathway perception, dynamic causal graph reasoning across Pearl's association / intervention / counterfactual levels, evidence-audit scoring, and critic-driven graph & memory evolution (Algorithm 2). The paper's MedEinst benchmark (5,383 DDXPlus-derived control/trap pairs) is not released; **test data is this parent repo's MCR400** (`mcr_val_seq100_v1` + `mcr_val_seq100_v2` + `mcr_val_seq200b_v1`). Pair metrics Acc_rob and R_bias are defined only when trap fields exist.

## Quick start

```bash
pip install -r requirements.txt
cd medeinst
PYTHONPATH=. python - <<'PY'
from src.llm import demo_llm
from src.model import ECRAgent, ModelConfig

agent = ECRAgent(
    llm=demo_llm(),
    config=ModelConfig(live_search_pubmed=False, live_search_opentargets=False),
)
result = agent.dci_pipeline("22M sudden chest pain, prior DVT, no fever.")
print(result.diagnosis, result.scores)
PY
```

Load MCR400 (does not download; needs the parent checkout):

```python
from src.data import MCR400Dataset
from src.evaluate import evaluate_cases

cases = MCR400Dataset(parent_repo_root="..")
print(len(cases))  # 400
report = evaluate_cases(cases[:0], predict=lambda x: "")  # empty demo
```

Live Qwen3-32B calls read OpenRouter keys at runtime from the parent `src/agentclinic_tree_dx/llm_client.py` fallbacks (or `OPENROUTER_API_KEY` / `OPENROUTER_API_KEY2`). Keys are **not** copied into this sub-repo.

Eq. 2 embeddings default to parent **MedCPT** (`ncbi/MedCPT-Query-Encoder`).

```bash
cd medeinst
PYTHONPATH=. python -m src.run_mcr --limit 1 --parent ..
```
