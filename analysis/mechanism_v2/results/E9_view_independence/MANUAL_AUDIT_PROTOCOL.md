# E9 root manual trajectory audit protocol

The queue is frozen before any root case-level judgment is recorded. It
contains all strict outcome discordances for the three causal contrasts, all
nine reference labels uniquely captured by the real-view union, SHA-ranked
same-outcome champion flips for the role and repetition contrasts, semantic
high-merge and low-merge quartile samples, and all explicit semantic-auditor
partition failures.

For each queued case the root auditor reads the clean vignette, all three
historical generator views, the frozen anchor assignment, each fresh selector
response and (when served) the heterogeneous semantic clustering. The root
then records:

- whether the locally evaluated reference match is genuinely equivalent or a
  scope/surface artifact;
- whether content added outside the anchor was decisive, merely useful,
  redundant or distracting;
- whether role names were explicitly weighted, changed only the narrative, or
  have no trace-level evidence of causal use;
- whether repeated evidence was treated as a vote, explicitly noticed and
  discounted, or left indeterminate;
- whether the semantic clustering preserved polarity, time, person, anatomy,
  modality and qualifiers;
- one trajectory-level mechanism label and a case-specific evidence note.

The Gemini clustering is a subcontractor artifact. Its labels are neither
accepted automatically nor used to replace root review. No failed response is
repaired, retried or imputed. The queue remains a development/mechanism audit,
not a new confirmation sample.
