# 错误位点、首次损坏与原因：三轴账本

本文件结合本轮概率样本和上一轮可重放见证；后者能证明缺陷存在，不能充当概率分母。抽取器原始输出率、管线最终可执行率和诊断排名是三个终点。

## 1. 完整错误分类

| 位点 | 必须核查的对象 | 典型失败及可观察反例 |
|---|---|---|
| 疾病身份 | 正文实体、指代、亚型、并发症、病因 | 借用检索 focus；父类体征收窄到参考文献标题中的亚型；兄弟病被错绑 |
| 谓词身份 | 表现、检测、结果、竞争疾病、措施 | 把鉴别列表中的疾病名当成能区分疾病的临床发现；测试名称代替阳性结果 |
| relation 方向 | 必要/充分/排除各自箭头 | 充分分支升为必要；正常参考范围升为疾病必要异常；反对证据升为排除 |
| relation 强度 | 常见、偶见、典型、特异、定义 | characteristic/hallmark 与 standalone sufficient 混用；低发生率被硬否决 |
| 字面极性 | P 与 NOT P 的完整文字 | 已写“absence of P”的 predicate 又给 negated；normal 不区分谓词本身是正常或异常 |
| 否定辖域 | NOT(A OR B) 与 NOT A OR B | 否定从组作用域漂移到单个成员；“不能用测试排除”变成“测试排除疾病” |
| 数字与单位 | 变量、比较符、值、区间、测量单位 | ≥ 与 > 互换；计数当成测量阈值；相邻另一个变量的数值借给本变量 |
| 连词 | AND/OR 与括号 | A AND (B OR C) 被压成全 AND 或全 OR；枚举逗号被臆造为必要合取 |
| 基数 | n、候选域、distinctness | 3-of-12 被缩成 3-of-4；同一事实证明两个同义成员而重复计数 |
| 嵌套与分支 | 每一子表达式及共享条件 | 年龄/运动条件本应约束整个分支，却变独立充分原子；多个major/minor计数合并 |
| 组边界与效力 | 同一目标、同一共同动作、完整成员 | 无关目标拼一组；成员各自具有冲突 relation；正确原子不组成正确规则 |
| 人群/时间/部位 | 规则适用域与事件身份 | 成人标准用于儿童；治疗后结果替代自然病程；跨病灶条件拼为同一病灶 |
| 例外与闭包 | unless、排除其他原因、例外路径 | 删除可满足的替代路径；未知被当阴性；开放病因集合被当成当前有限列表 |
| 评分程序 | 有符号权重、总分、阈值、分级 | 负分项目变单独排除；正分条目变充分；评分表被拆成任意加权表决 |
| 任务身份 | 诊断/分类/检查/治疗/预后/研究纳排 | “满足A和B应检查”变成“A和B确诊”；手术条件变疾病必要条件 |
| 引文与来源 | 原文祖先、跨度、标题、版本、窗口 | 合成短引文；借邻句授权；以错误标题指定主语；cache/窗口身份缺失 |
| 全新无源主张 | 是否存在任何可识别来源祖先 | 仅在实际输入及可查同文档均无祖先后判纯幻觉；错误主语/方向不自动属于此项 |
| 接口契约 | 枚举、类型、字段有效性 | 语义正确但 relation 越界；非法数值对象；不可执行 prose 条件藏进 noun phrase |

前17项是语义/来源位点，第18项单列契约违规。引文不逐字与无源主张也必须分开。每条规则允许多个位点；它们的百分比不能相加为100%。

## 2. 原因不能从错误字段直接反推

| 首次损坏阶段 | 已有证据 | 可支持的原因 | 不能支持的更强结论 |
|---|---|---|---|
| 原文→结构化正文 | 原始 StatPearls XML 与解析器重放；本轮 article-25882 | parser 选择 bibliography article-title；缺少层级与成员上下文 | 全部目标错误均来自模型知识缺失 |
| 正文→实际窗口 | 6,000字符裁剪；列表尾部没有引导或完整域 | 输入不足、上文/表头/域丢失；应标 ambiguity | 丢失所有规则均是抽取遗漏 |
| prompt→表示约束 | 提示词原文与 schema 可直接读取 | “named n-sign set→all”“任意and都拆开”“characteristic→pathognomonic”等不当默认 | 每条符合错误默认的输出唯一由prompt造成 |
| schema→不可表达规则 | 无递归 children、group effect、权重/域；可构造不同公式投影同字段 | 表示契约不充分；即使模型理解也不能忠实编译某些表达式 | 所有浅层组都无法表示；所有嵌套都需要高阶逻辑 |
| 输入/prompt→原始 JSON | 保存的原始缓存已包含错误；同字段归一化未改变 | 错误首次出现在模型生成边界；违反清晰指令的具体案例可识别 | 由此证明LLM固有容量极限、或唯一原因是prompt |
| raw→规范化 | 缺n的at_least_n改为any等确定性见证 | compiler在没有证据时猜逻辑 | 所有实际错误由规范化造成；四臂重建已排除这一泛化 |
| 规范化→准入/门闸 | G2、G3、E9、邻句许可等重放 | 正则门闸进行未经授权的语义重写 | gate通过代表原文忠实 |
| 准入→绑定/建组 | 预去重删共享成员、局部g1跨窗口合并、首匹配主语 | rule identity与临床identity不充分 | 更改prompt即可消除程序破坏 |
| 组→动作/排名 | 组只数presence；弱反证硬排；重复事实多票 | evaluator未执行原命题，或相关证据被重复使用 | 所有v2排名变化都由组造成 |

证据等级：A=确定性程序或文本硬矛盾；B=原始缓存定位/受控干预；C=机制相容但未隔离；U=尚未识别。同一个例子可同时有A的“字段缺失”和C的“该缺失诱发此次模型错误”。不能把C批量改成A。

## 3. 判据组的“一等公民”究竟缺在哪里

当前 `criterion_group={group_id, logic, n}` 的 `logic=all/any/at_least_n` 能承载浅层 AND、OR、至少n。因此“完全没有连词”过强。确切缺口是：组不是独立规则对象，而是成员行上的附注；成员有各自 relation/polarity/modality，组没有唯一 target、effect、scope、provenance、expression root。

一个平坦同质组可以隐式保存效力，故不能仅因格式平坦判错。可是系统不要求同质、不拒绝冲突、不保存递归结构，运行时还读首成员的logic/n，用任何成员的required_for且obligatory触发组必要性标记，并通过最大modality决定整组权重；硬否决还须出现违反且不属于soft_group。表示风险、生成错误和执行错误于是互相放大。

“单原子满足就等于整组满足”需要分三种情况：

1. `any` 的一个成员为真本来就足以满足表达式；错误只在其是否具有确诊/排除效力。
2. 对有效目标数大于1的 `all`，只有一个成员命中时，代码没有把 `met` 设为真，却仍给部分正分；诊断规则被当作软分数使用。若坏组同时携带较小的n，代码采用target=n而非成员数，甚至可能真正把单次命中置为met；这需另查字段是否保留到执行边界，不能混为一种现象。
3. 原子去重先于建组，可能删掉其他组的共享成员；只剩一个成员的组随后丢失组身份，回到原子规则。这才会把整个充分组错误缩成单原子。上一轮 E08 已用开启充分确认的明确配置证明该风险；默认未开启时不应声称当前所有运行都发生硬确诊。

组满足性必须先计算 signed literal（包括数值/单位/事件），再递归求表达式真/假/未知，最后读取唯一组效力：必要、充分、排除、定义或软证据。`all` 不意味着“疾病必要”，`any` 也不意味着“不能刚性”。

## 4. 修复与验证应分别针对原因

1. 来源层保存真实标题、层级、完整域、跨块闭包和原文跨度；缺失成员时输出 unresolved。
2. 建立独立 Rule 对象：target、use、scope、expression、effect、provenance。递归表达式包括 AND/OR/NOT、COUNT(domain,distinct,n)、数值比较；评分另有 signed terms 与阈值。共享叶节点用稳定ID引用，去重不得删除引用。
3. 抽取分“原文完整规则定位→中性逻辑转写→结构编译”，每阶段保留源跨度。少数必要的复核调用只审方向、组作用域和数值等争议，不让自由式修复产生新规则。
4. prompt明确区分必要/充分/排除，禁止从典型集合推必要，禁止把检查/治疗条件升级为诊断；没有明确支持的字段返回 unresolved 而非猜默认。
5. compiler拒绝非法枚举、混合组目标/效力、缺n、不可恢复作用域，保存原始输出和失败原因；不可悄悄改成any。
6. 执行器用统一组级方向解释器；unknown不能变阴性；软证据按独立医学事实与来源依赖处理，文献产量不能冒充似然比。

后续因果实验采用同一批冻结来源、同模型/provider/预算下的 `原prompt/明确方向prompt × 平面schema/一等组schema` 2×2，另加 source-only span baseline。每个条件重复运行；主要终点为来源规则忠实召回与输出组精确率、纯幻觉和无效接口率，次要才是覆盖/数量。随后固定规则和病例事实，对新旧编译器/执行器交叉重放，避免把提示词与程序修复合并成无法归因的升级。病例74是开发反例，不能再当held-out证明。

本轮不以重新抽取覆盖历史缓存：当前能力边界必须对应已产生回归的真实输出。历史新旧prompt同源配对能说明结果如何变，却不能完全隔离provider波动；本轮没有新模型干预，prompt与模型容量的独占因果贡献仍保持未识别。
