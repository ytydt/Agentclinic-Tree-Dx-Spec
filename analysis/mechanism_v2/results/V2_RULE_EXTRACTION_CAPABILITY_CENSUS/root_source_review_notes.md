# 固定8窗口的第二次来源阅读

根审核员于各窗口模型输出复审前通读固定 `review_selection.json` 的8个完整窗口。下列记录保留源侧分段边界；最终标签修订另存在review文件，不覆盖先前清单。根审核员已知研究主题，不能声称完全双盲或人类临床专家复核。

- S1-02：大部分是引文、影像检查建议和证据缺口，不应抽成“CT必要/充分确诊”。“大部分腹内脓肿术后形成”是可纳入的弱病程/背景关联；CT维持准确性的操作优势不属疾病判据。
- S1-07：表格确实区分cyanotic/non-cyanotic两列，各病可获得弱分类/表型关联。不能把cyanosis升级为每一个列内疾病的必要或充分条件；正文提到但表格没重复的pulmonary atresia/truncus仍可纳入一次。
- S1-09：早期发育损伤的推测机制与可观察表型分开；PA-IVS的三尖瓣异常、冠脉异常连接、右室高压和RVDCC的灌注依赖可作为诊断性描述。RVDCC进展/差预后不应升级为确诊。
- S1-16：RLQ鉴别列表是逐独立疾病的弱关联，异位等简称可保持原文含糊程度。Alvarado是完整有权重程序；≤3只说unlikely，≥7是会诊、4–6是考虑CT，不能把7分当确诊。总10分不代表诊断阈值。
- S2-09：主要是psoriasis与心血管病/危险因素的弱关联。文献表内结果有冲突，必须保留群体/研究范围，不能将个别“无关联”变成psoriasis排除心血管病，也不能把各重复meta-analysis当互相独立规则票数。
- S2-15：3-of-12明确，但窗口只提供尾部4项；完整成员域不可补造。Catatonia specifier还要求在另一精神障碍病程内、并排除其他医学原因。用只留下的4项构造3-of-4改变了域。35%是人群发生率，不是诊断阈值。
- S4-11：临床可见虱体足以支持可见体征的pediculosis识别；青春期前papules/nits否定有年龄范围。骨髓炎的急/亚急/慢性及传播路径独立；儿童部位受新生儿/血红蛋白病和年龄约束，不能删掉亚群后给所有骨感染统一部位。
- S4-12：移植术后危险因素和peritonitis表现是弱集合；免疫抑制可掩盖疼痛，缺痛不能硬排。CMV供受者血清状态须针对同一病毒，不能将HSV阴性受者与EBV阳性供者随意拼成CMV条件。晚期感染病原谱不同于“病毒任意一项即可确诊”。
