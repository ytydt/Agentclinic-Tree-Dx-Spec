# 这个目录在讲什么（面向初次阅读者）

共用术语见 [../READER_GUIDE.md](../READER_GUIDE.md)。本文只讲这个目录独有的东西。

## 一句话

之前的审计只给出了「这里错了、那里错了」的样例，**没人知道错误占多大比例**——因为没有分母。这个目录去把分母补上了。

答案：**指南里的一条完整规则，被完整忠实地抽出来的概率约 16%。**

## 为什么需要「两个分母」

问「抽取准不准」其实是两个不同的问题，答案差很远：

| 问题 | 分母是什么 | 答案 |
|---|---|---|
| **指南里的规则，有多少被保住了？** | 原文里实际存在的规则（286 条）| 完整忠实 **15.68%** |
| **抽出来的一条断言，有多大概率可信？** | 抽取器实际吐出的单元（180 个）| 原子 **45%**、完整组 **20%** |

第一个问题问的是**召回**（漏没漏），第二个问的是**精确**（吐出来的对不对）。只报一个会严重误导。

## 「来源先行」是什么意思，为什么重要

如果先看模型输出、再回去原文找对应，就只会数到「模型抽到过的那些规则」，**漏掉的规则根本不会进入分母**——这会把准确率虚高地抬上去。

所以这个目录的流程是反过来的：

1. 先随机抽 64 个原文窗口；
2. 审阅者**在没看过任何模型输出的情况下**通读原文，自己列出里面有哪些规则（得到 286 条）；
3. 把这份清单**冻结并存哈希**；
4. 然后才揭示模型输出，逐条对照。

这叫 **source-first（来源先行）**。冻结哈希是为了证明清单不是事后改的。

## 需要解释的专用说法

| 说法 | 平实解释 |
|---|---|
| **source rule（来源规则）** | 原文里的一条完整规则。一整套「四条满足两条」算**一条**，不能因为抽到了其中一个成员就算成功。 |
| **output unit（输出单元）** | 抽取器吐出的一个独立对象：要么一条原子断言，要么一整个判据组。组的成员不再重复计入原子分母。 |
| **忠实 / 曲解 / 遗漏 / 无源虚构** | 四种判定。**忠实**＝完整正确保留；**曲解**＝有原文出处但意思被改了；**遗漏**＝完全没抽出来；**无源虚构**＝找不到任何原文来源（真正意义上的「幻觉」）。 |
| **严格无源虚构 0/180** | 本次**一例都没检出**。但这个定义很严格：它要求找不到任何可识别的原文祖先，**不是**「引文没逐字对上」，也**不是**「原文不支持这个关系」。0/180 只说明这次没检出，95% 上界约 3.64%，**不证明不存在幻觉**。 |
| **加权比例 vs 样本整数** | 31/272 不等于 15.68%。抽样是分层的，每个窗口按被抽中的概率反过来加权，所以整数和百分比对不上是正常的。 |
| **可表达性：impossible / lossy** | 审阅者判断「现有的扁平 schema 能不能装下这条规则」。**注意这是审阅者的评估，不是数学上界证明。** |
| **反模型（countermodel）** | 一组具体赋值，使得「原文规则为真、抽出来的规则为假」（或反过来）。用来严格证明两者不等价，而不是凭感觉说「不太一样」。 |
| **AST** | 抽象语法树，就是把「A 且（B 或 C）」画成树形结构。用来精确表示嵌套逻辑。 |
| **cross review / override** | 复审。初判被改动时，**初判和修改理由都保留**，不是直接覆盖掉。 |

## 几个关键数字（都可在 `census_metrics.json` 复算）

- 来源侧：完整忠实 **15.68%**（95% 聚类区间 9.27–22.98%）、曲解 42.19%、遗漏 42.13%。
- 「有任何可识别后裔」的比例是 **57.87%**——抽到点东西容易，**保住整条规则难**。
- 新提示词比旧提示词只高 **3.07 个百分点**，配对区间 −0.60 至 +6.60，**不能宣称改善**。
- 按结构分：**浅层复合组 7 条、嵌套/域组 16 条、评分程序 1 条，合计 24 条，没有一条达到完整保留**。
- 输出侧：原子忠实 45%（区间 36.4–53.9%），完整组忠实 **20%**（区间 11.8–31.8%）。
- 按来源：wikem 最差（28 条规则里 0 条忠实、24 条遗漏），statpearls 相对最好（108 条里 18 条忠实）。

## 一条被作者自己撤回的推论（值得学习的地方）

审计一度以为发现了「n=1 的两成员组会让单项满足整组」这个大问题。逐阶段核验后发现：那个坏字段在**规范化阶段就已经被清掉了**，历史存档里并不存在。于是作者**主动撤回**了这条推论，并把撤回过程记录在 `FINAL_SEMANTIC_REVIEW.md` 里。

读其他结论时可以参考这个标准：作者区分了「原始输入里有坏字段」和「这个坏字段真的影响了结果」。

## 读结论时的边界

- 审阅者是 **AI 代理**，不是人类临床专家。先冻结来源确实减少了偏差，但审阅者**知道研究主题**，所以不能称完全双盲。
- 统计区间**只含抽样误差**，不含审阅判断误差、规则分段口径误差。
- 来源样本来自 55 篇文档、输出样本来自 133 篇；同一篇文档里的多个窗口**不是独立医学事实**。
- 覆盖的是这 11 例实际检索到的 v2 窗口，**不是全部指南库，也不是所有大模型的固有上限**。

## 最重要的三条结论

1. **规则级召回极低（约 16%），而不是「抽出来的大部分是对的」。** 这两件事经常被混为一谈。
2. **错误的主体是「有出处的曲解」（约 49%），不是凭空捏造（0/180）。** 意味着靠「检查引文是否存在」这类手段抓不住主要问题。
3. **判据组是重灾区**：完整组忠实率只有 20%，而带嵌套、带范围、带计分的结构**一条都没保住**。
