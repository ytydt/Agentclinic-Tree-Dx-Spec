# 阶段、适用范围与分支规则补充协议

日期：2026-09-08。基线：`cursor4@bbc036e8a6ec93583be915a4609fe86278ed062c` 中的 `RULE_EXTRACTION_EXECUTION_REDESIGN`。

本任务补充上一设计的可执行规格；不覆盖、改写或宣称旧设计已经部署。旧合同已有 `applicability`、流程目标、诊断动作许可和“建议检查不等于结果证据”的原则。本轮需要补齐可存储的阶段/意图/对象类型、跨阶段证据权限、守卫与规则体的区别、条件分支和例外解析、未知与冲突处理，以及旧数据迁移和验收。

验收分为：字段与类型完整性；合成事实下的操作语义；来源与旧设计的差量映射；迁移及研究方案。所有合成规则的临床使用授权均为 false。有限样例检查器不是源文忠实性证明器、医学标准实现或一般一阶逻辑求解器。

尤其检验以下边界：建议/医嘱/执行/结果不可混用；治疗资格或禁忌不自动推出疾病真假；无疾病对象的流程规则合法；范围不适用不等于诊断条件失败；未知范围不走默认 else；交叠、空隙和例外需显式政策；可嵌套表达式的表达能力不代表抽取器会正确恢复其作用域。

两个任务各有独立主报告、机器可读数据与复现说明。实现缺陷审计位于相邻 `IMPLEMENTATION_DEFECT_AUDIT`，本目录只承担设计补充。
