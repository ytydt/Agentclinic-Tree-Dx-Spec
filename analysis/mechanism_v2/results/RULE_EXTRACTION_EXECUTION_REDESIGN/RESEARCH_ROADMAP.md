# 忠实规则抽取与安全执行：分层研究路线及确认实验

本方案基于 cursor4@6fa8fd7aa2548cc01ac81f2d5261801190244d27 的[差量审计](../V2_INDEX_DIFFERENTIAL_AUDIT/REPORT.md)及[原始文献调研](../FAITHFUL_RULE_EXTRACTION_LITERATURE_REVIEW/REPORT.md)。这是待实施研究方案，**没有在本轮完成新模型实验、临床专家盲审或证明改进有效**。机器可读设计见 [experiment_matrix.json](experiment_matrix.json)，预算和样本量计算见 [research_planning_calculations.json](research_planning_calculations.json)。源规则、规则组、患者事实和诊断答案分别有自己的参考，不让答案正确替错误规则背书。

## 1. 研究问题、对象与不能混用的样本

首先检验“能否更忠实表达并正确执行给定指南”，然后检验“更忠实是否在可用信息和成本相同时改善完整诊断”。两个问题可以得到不同答案：拒绝错误目标票可能使历史 proxy MRR 下降；保留正确病灶证据也不意味着它就是题目要求的病因答案。

| 样本/对象 | 允许用途 | 禁止推论 |
|---|---|---|
| 11病例 × 历史四臂、前轮64来源窗口及180输出单元 | 开发回归、错误触发器、符号/组/连接反事实、方案选择 | 新确认集、800例总体因果比例；64窗口和180输出互换分母 |
| 已多轮分析、开发与选模的 DA400+MCR400 | 扩展开发、估计新实验的方差和工作量 | 因为未用于某一特定补丁就恢复为全新 held-out |
| 新来源窗口集 | 在冻结抽取器上估计来源忠实率、遗漏、严格无来源幻觉和可表示边界 | 与既有输出对齐后才选择“容易标注”的源规则 |
| 新独立病例及其来源范围 | 在冻结方法、阈值和资源预算下确认完整诊断与风险 | 仅更换题号/近义改写旧病例；只留给定规则能生成的病例 |
| 合成最小世界/真值向量 | 隔离逻辑算子、作用域、缺失值及程序执行 | 临床表现率、真实病例风险或 source coverage |

新来源先抽样、登记完整规则，再查看任何方法输出。抽取评审者看源文及候选翻译，不看病例金标/排名；临床判分者看病例、预先冻结的任务目标及方法匿名输出，不看规则臂。至少两名具备相应领域能力的独立审阅者，分歧保留原始记录、再由第三方裁决。若只能AI审阅，必须将其写为AI审计结果，不能替代这道确认门槛。

采用来源家族分层概率样本：覆盖叙述、列表、诊断标准、表格、跨段例外；原子、平面组、递归组、计数域、评分程序、必要/充分/元规则分别报告。复杂类型可富集以研究机制，但总体率须使用预登记的抽样权重；不能把富集样本直接当指南库普查。叶子、原子命题、完整程序和窗口各自计数，一个十叶组只算一个完整组机会，另报叶级诊断误差。

## 2. 冻结六个层次的参考与分母

### 2.1 来源可用性与抽取能力

来源能力先问完整指南是否支持目标，曝光能力再问所需内容是否进入抽取payload。规则抽取的遗漏不能替代“文献本身没有”，来源引用存在也不等于引文支持这个关系。

**源级主分母**为独立登记且可裁定的唯一规则/完整组数 N_src = F + D + O。F要求主语、谓词论元、逻辑依赖、量词域、否定、方向、作用范围、例外、阈值和根效果全部忠实；组被拆成若干正确叶子而失去组合关系，整组是D，不是F。存在可追溯的部分翻译但内容被改写/丢成员是D；没有任何对应输出是O。多个同义输出中有一个F时，源召回可记F，但若同时输出矛盾D，则另报“该源完整输出包无冲突忠实率”，并在输出精度中计D，避免生成大量互斥猜测刷召回。

源文存在真正歧义或引用缺页导致无法裁定的条目，另记 A_src 与理由，不强迫进入F/D/O；同时报告 A_src / 全部登记源单元和将全部歧义计为失败的保守敏感性界。自然语言宏谓词可能在文字上忠实、却没有可执行解释：分别记录语义F和形式支持状态，不能靠把整个组塞进一个字符串取得“可执行F”。

**输出级分母**为所有实际生成的唯一规则/组单元，而不是仅成功解析或成功绑定的行。对每项分别标：忠实、可追溯曲解、源内真实但任务范围不合、严格无来源H、溯源未决。H只用于经规定范围检索后，找不到任何可解释祖先的新增命题；错接、反向、漏限定和源内拼接通常属于D，而不是用户所定义的H。H率附溯源搜索边界，不能把“当前窗口没找到”叫“整个指南库不存在”。同时报告原始输出数和语义去重数，不能把重复幻觉去重后只报较低错误率。

空响应、拒答、截断、格式失败、网络失败、编译不支持、求解超时分别按调用数记账；其造成的源遗漏仍进入意向分析O，但不能仅用O隐藏运行失败原因。部分可恢复输出也保留未恢复部分。解析失败内容由审阅者判断是否含可辨识规则，不通过跳过非法JSON美化输出H率；确实无法分段的结果单独记不可判输出，不捏造规则条数。

### 2.2 编译、患者事实、执行和任务终点

| 层次 | 主评价对象/分母 | 必须配对报告的限制 |
|---|---|---|
| 形式编译 | 合法AST、类型/自由变量/引用/作用域检查；参考等价 proved / refuted / unknown / unsupported | 语法有效不等于源忠实；等价结论以固定符号映射及独立参考IR为前提 |
| 患者事实 | 完整事件、测量对象、值、单位、标本、部位、时序和否定的准确/遗漏；审定可连接机会的join精度与召回 | CD31/PECAM-1别名应连；血/组织、前/后骨间神经、mPAP/PASP不能因相近而合并 |
| 执行 | 固定IR与事实后的真值、组根效果、诊断动作、程序得分及proof一致率 | 未知≠阴性；检查名≠阳性结果；规则真≠有权确诊/排除；无资格行不能经claimants间接投票 |
| 硬动作 | 错误排除/全部排除动作；错误确认/全部确认动作；每病例是否至少一次错误硬动作 | 同时给正确候选被误排除/正确候选机会，错误候选被误确认/错误候选机会；分母不能互换 |
| 诊断 | 预先裁定的完整任务答案top1/top3、完整MRR、范围正确性、证据支持性 | 原历史proxy单列；病因、病灶、并发症可以共存，不因标签不同就互相排除 |

硬动作的医学真值与答案角色也分开裁决：真实但非本题目标的并存病灶，不能仅因未等于金标而计为“假确认”；若引擎把它当作互斥最终答案，另记任务角色/范围违规。误排除同样不能仅凭proxy名称判定，必须回到实际被排除的完整概念及病例支持。

完整答案裁决必须明确任务要求的病因、亚型、部位、阶段及复合关系。例326的Brucellosis与Epidural abscess可同时为真，但不一定回答同一问题；例179的Thrombocytopenia不自动补成hypoxia病因。固定完整候选的实验回答选择能力，候选生成实验回答覆盖能力，两者不能混算。

一般一阶逻辑的等价检验不能保证总是终止。先冻结可执行片段、logic_profile、量词域、类型与数值/时间理论，以及数据完备假设。建议首轮支持递归and/or/not、有限声明域exists/forall/count_distinct及类型化比较/事件关系；完整数学表达可以保留，超出可执行片段明确标unsupported，不自动压平。solver timeout为unknown。患者域不完备并非一律unknown：forall已有FALSE反例即可为FALSE，exists已有TRUE见证或at_least已有足够不同见证即可为TRUE；其余情形按所声明的部分信息语义求值。必须把“源组结构未知/缺成员”与“源组结构已知、患者域未完全观察”区分，不能用发现一个见证补造未知的原规则结构。

**经典二值公式等价不等于含未知值的运行等价**：二值逻辑中 A∨¬A 与 TRUE 等价，Strong Kleene K3中A=UNKNOWN时前者为UNKNOWN。参考IR须记录logic_profile、完整性与冲突策略；求解器只在其声明的语义和假设内证明等价，不能将经典FOL化简结果直接替换三值程序。跨后端转换需覆盖TRUE/FALSE/UNKNOWN及单独的conflict状态或冲突处理策略。有限反模型能证明相应语义下不等价；有限枚举没有反模型不能宣称任意域等价。评分表采用独立ScoreProgram（条件、有符号权重、互斥档、分档及unknown区间），元规则/检查/治疗/分类工作流采用独立动作类型，不强行当成二值疾病蕴涵，也不默认回收为诊断软票。

## 3. 冻结对照臂及文献方法的可检验改造

| 臂 | 固定定义 | 它实际检验什么 |
|---|---|---|
| M0 Legacy | 冻结旧抽取器、提示词、schema及原执行行为；保留历史缺陷 | 历史测量参照，不能作为安全部署臂 |
| M1 Fix-only | 相同抽取输出；只修可证明的身份、去重、缺失/数值、组根动作、无资格claimants和错误执行通道 | 确定性实现缺陷的收益和揭露的残余；不补写源语义、不暗中重译 |
| M2 Recursive IR | 源锚点+符号/论元表+递归表达式+根效果，受语法/类型/引用约束生成和编译 | 表示容量与结构约束；合法的错误AND/OR仍可能通过 |
| M3 Compose+Verify | M2加原子/连接结构分解、受控释义、区分读法的反模型、带原文修复和回滚；尝试数冻结 | 组合解析与独立验证的增量；同一模型重复自洽不能当保证 |
| M4 Reference | 双人独立源审定的参考IR；患者参考事实/连接及参考执行结果按实验单独提供 | 表示、事实和执行的条件上界；不列入等成本部署排行榜 |
| N0/N1 | 冻结固定候选的无RAG决策器；实际来源RAG决策器 | 源利用与端到端参照，任务和预算一致 |

M1的旧格式适配若无法恢复连接结构，必须标记unsupported，不能从默认any生成“参考结构”。保留原抽取语义审计：执行器安全拒绝D不等于抽取F增加。M0→M1与M1→M2分别报告，防止把关闭硬规则或换候选集的效果归功于更忠实提取。

方法借鉴的依据和必要反证：

- [PICARD](https://aclanthology.org/2021.emnlp-main.779/) / [Synchromesh](https://arxiv.org/pdf/2201.11227) 支持约束生成；E04必须给出“合法但错误”的连词/作用域结果，不能只报parse rate。
- [MRS](https://www.cl.cam.ac.uk/~aac10/papers/mrs.pdf) / [CLOVER](https://arxiv.org/html/2410.08047v2)支持逻辑依赖与分解；E05提供参考原子和参考结构的独立oracle轴，区分符号错误与结构错误。
- [Logic-LM++](https://aclanthology.org/2024.nlrse-1.6.pdf)支持带源修复/回退；E07冻结修复前输出，记录修对、修坏和错误迁移，测额外调用究竟买到什么。
- [HL7 CPG](https://hl7.org/fhir/uv/cpg/methodology.html)、[CQL](https://cql.hl7.org/09-b-cqlreference.html)提供知识工程及可执行分层；E02/E12必须覆盖AllTrue对空/全null集合等与临床完备性不一致的后端边界。
- [Text2MDT](https://arxiv.org/html/2401.02034v1) / [CPGPrompt](https://arxiv.org/html/2601.03475v1)支持结构和人审参考；不能只在已审核树生成的病例上确认自动抽取效果，E17需要独立自然病例。

这些是待验证的组合方案。KG、Python、树或skill只要保存同样语义合同均可作后端；独立的后端转换实验才回答载体效应，不能同时换提示词、候选集和求解器后归因于某一种格式。

## 4. 分阶段实验：每步有可推翻的假设

机器矩阵对每项给出输入、因子、固定项、主要/次要终点、反证、交付和推进门。以下是优先顺序，不要求先把全部18项大规模跑完再发现前层不成立。

| 阶段 | 实验 | 独立结论与交付 |
|---|---|---|
| P0 计量冻结 | E00、E01 | 版本/缓存/来源谱系；完整源规则库存和双参考；分母及预登记统计方案 |
| P1 确定性内核 | E02、E03、E12 | 旧行为精确回放、参考IR真值/动作向量、仅fix的局部与联合效果；不消除合法硬规则 |
| P2 抽取能力 | E04–E09、E14 | 同源预算下的F/D/O/H、oracle结构/原子差额、修复四格、保义与反义配对 |
| P3 病例接口 | E10、E11 | 参考IR×事实×连接×执行的条件上界；别名与反合并、候选层级/频率干扰 |
| P4 来源曝光与风险 | E13、E15、E16 | 同内容恢复/格式/真实曝光的效应；固定候选完整诊断、硬动作coverage-risk |
| P5 全新确认 | E17 | 冻结单一方案的新来源+新病例端到端验证；完整诊断与风险、预算及失败账本 |

### 4.1 同源抽取实验与oracle拆分

E04固定完整payload、focus、模型/provider和输出预算，先比同一调用内的平面/递归表示与约束，再比各完整方法。提示词变化和schema变化若同时发生，只能解释方法包；另做 prompt × representation 可识别子效应，旧格式不支持的组计unsupported而不是删除。

E05用 自动/参考原子 × 自动/参考逻辑结构 四格，保持源语句和符号表接口一致。参考原子应包括主语、谓词论元、标本/时间/否定等，不能只给金标疾病名。参考结构oracle不得暗中补上缺失医学概念；接口不兼容的单元单列，不能只比较两个oracle都成功的容易子集。

E07用完整规则作为配对单位，分别报告 错→对 / 对→错 / 错→错 / 对→对；错→错再分保持原错、错误迁移、引入新错。修复前后保留源链接及solver状态，正确但被修坏的组不能因最终答案没变而漏报。去掉原文、去掉反模型、相同预算多次独立翻译三个对照，检验收益来自验证信息还是更多采样。

E08保义实验包括α变量更名、组成员/段落重排、同一事实别名重述、无关段落、合法括号改写；新旧输出须在固定符号映射、logic_profile及数据完备假设下等价、临床动作相同；仅经典二值等价的化简不能默认作为K3保义变换。重复一个标准不增加count_distinct和证据权重。E09则改变AND/OR、∀∃顺序、必要/充分、否定位置、域限制、时间/标本/数值界、例外归属，选择有已知区分世界的配对；系统必须改变正确作用槽位及相应世界的动作。只会对任何改写保持不变不是稳健。

### 4.2 固定候选、参考事实与执行器的交叉

E10分两步：先固定IR交叉 自动/参考患者事实 × 自动/参考join，再固定参考事实/join比较自动/参考IR及旧/新执行器。最小的IR×facts×executor八格可作总览，但不能用“facts+join联合oracle”定位其中一个接口。关键病例原始完整vignette保留，观察模型把值放入何字段，避免参考facts比原vignette偷偷多了信息。

E11区分同义项、父子类、病因/病灶、无关项、真实近邻。冻结原始IR及事实，增删/重排候选并复算全体，不仅看目标分。若增加同义候选改变既有概念的证据资格、hard动作或概率，应解释其语义依据；词面频率不构成依据。合法父类证据可以支持子类的一般性质，但不能自动取得区分子类的特异性。跨病因/病灶同时为真的候选需要任务角色和复合关系，而不是强制互斥。

### 4.3 新旧曝光必须重新做成能识别的实验

E13至少包括三个独立因子实验，不能简单把历史四臂换名为“因果因子”：

1. **内容恢复**：同一文档/章节、同一focus、共同核心文本、相同顺序，将预审定的确实缺失列表/例外补回；避免用硬token cap再次裁掉共同文本。对照补入等长无关但来源真实的段落，测长度/干扰效应。
2. **格式重建**：相同词项、数值、单位和医学命题，比较tab串/保留行列表/结构表格，单独检验格式触发；真表格跨行语义不能用随机词序当保义格式对照。
3. **系统曝光**：固定病例/focus候选和模型配置，真实旧/v2检索、窗口选择、截断各自产生完整payload；再以共同payload交集、两侧独有payload和人工source oracle展开。此臂估计整体升级，不等同于纯内容恢复。

内容恢复和格式可形成受控2×2，前提是四格经源审定具有预期差异且无其他段落替换。历史缓存共同job字节一致，只是重复使用一次结果；新重复抽取须独立记录provider调用，不能把cache命中当重复稳定性证据。已有诊断基线没接入RAG时，须先明确N1真正调用了哪条来源通道。

## 5. 预算、重复运行与防泄漏

分别给两种成本曲线，而不声称一种自动推出另一种：

- **等调用预算**：预登记B=1、2、4等可行档位。M3将预算分给分解/验证，M0/M2可按冻结策略分给独立翻译与聚合；这一对照检验调用分配策略，纯schema效应用E04的单调用固定实验。
- **等token额度**：统一计入系统提示、重复源文、符号表、输入/输出、修复、失败/拒答及重试的总额度。报告实际消耗和额度，不把同一上限说成实际token完全相等；预算达到即按冻结策略结束并记未完成。若做实际成本匹配，先登记容差和分配方式，不能事后挑选成功运行或填充无用调用。

同时记录模型/provider版本、采样参数、延迟、失败重试、缓存身份、retrieval/solver CPU时间及人工审阅时间；oracle人审成本单列。新cache key至少覆盖原文、focus、提示词、schema、代码与provider配置身份，禁止复用旧schema响应后声称新抽取器已测。

开发阶段关键臂默认5次独立运行，用于估计方差；确认阶段在冻结样本量计算前决定固定重复数及可部署聚合规则，不能选最好一次。若主策略是单次抽取，则用预登记的单次结果或每病例运行分布估计，不把5次中的任一次正确计成功。统计以病例/来源家族为聚类单位，多次运行不产生更多独立病例。

来源分割需审查三层：文档/版本复制、概念同义或父子重叠、指南家族引用/转载。先构造近重复及共同祖先图，以连接分量或预冻结家族分割；报告source-cold、concept-cold、双cold及家族外推的不同结果。综合指南可能形成巨型连通分量，不能为了凑比例切断已知依赖；若无法同时做到三层不重叠，明确标记哪层留出成立，并新增外部家族。提示词例子、修复测试、概念词表和参考程序也属于训练/开发资源，须进入泄漏账本。

对新病例去重原始vignette与答案解释，包括已使用800例的近义改写和同一病例报道。模型预训练污染通常无法完全排除，应报告可检查边界；新收集不自动保证模型从未见过。

## 6. 阶段门槛与失败后的行动

这些是**建议的预登记决策门**，不是已经达到的成绩，也不是临床部署许可。最小有意义改善量应在新开发pilot后、确认集解盲前冻结。

| 推进门 | 必须通过的条件 | 失败时下一步 |
|---|---|---|
| G0 计量可复核 | 全部计划样本与版本可追踪；F/D/O与H分母可重建；盲审/分歧账本完整；历史回放无漂移 | 先修计量，不宣称方法效果 |
| G1 内核语义 | 预冻结支持片段及logic_profile全部参考向量和关键语义mutant通过；unknown/冲突/不完备不触发未授权硬动作；合法硬排除/确认仍可发生 | 阻断失败的动作类型，补内核；不能关闭全部硬动作后声称组执行正确 |
| G2 忠实抽取 | 主要完整组F召回相对M1改善的配对区间下界>0，并通过无冲突完整输出包F共主门；输出忠实精度非劣、严格H及溯源未决率不越预登记限值；覆盖与全部atom结果完整报告，原子F通过预登记非劣界（−2pp仅规划候选） | 若只提升parse rate或降低覆盖换高精度，不能进入“忠实提升”结论；定位身份/结构/来源歧义 |
| G3 接口转化 | E10证明自动IR收益在自动facts/join下至少部分保留；E11身份/去重反事实通过；跨层失败账本闭合 | 若收益只存在oracle facts，应先改事实接口，保留源抽取收益的独立结论 |
| G4 硬动作风险 | 在开发集选定阈值后冻结；新确认中错误硬动作上界低于预登记风险容忍，并达到预登记非零覆盖及合法硬动作召回 | 风险失败则该动作保持研究/审核模式；覆盖太低不能称问题解决 |
| G5 完整临床结果 | 唯一预登记主要方法与对照，在共同预算下完整答案主终点检验通过；proxy、子组、风险、调用完整披露 | 仅proxy升或有不被允许的伤害则不晋级；不能回确认集调阈值后继续称held-out |

G2不能仅靠每源多生成互斥猜测、碰中一个F晋级：无冲突输出包和输出侧约束与召回门同时要求通过，其边界在新开发pilot后、确认解盲前冻结。G2的统计显著改善不能替代足够效应，建议同时预登记完整组F改善10pp为规划目标，最终是否可达由新开发pilot决定。G5可选完整top1为唯一主要终点、3pp为规划效应；top3/MRR为次要。若业务问题确实更关注top3，则在查看确认结果前把top3指定为主要，不得在三个指标间事后挑显著。

G4建议首先研究≤1%的每病例错误硬动作风险界，再按代价细分误排除与误确认。风险界是研究选择，并非已被医学实践认可的统一安全阈值。必须同时预登记覆盖下限/有条件真硬动作召回：从全不动作到全动作画coverage-risk曲线，不能靠全拒答得到“零错误”。选择阈值用开发集，确认集仅评估冻结点及带同时不确定性说明的整条曲线。

每个实验设最大调用/修复次数与总样本数；固定N设计不因暂时显著提前停止。若需要序贯停止，预登记alpha spending或confidence sequence。遇不支持逻辑不自动改写为弱逻辑；遇来源歧义不迫使一个硬答案。修复臂若修坏不低于修对，或只在增加成本时变好而等预算无优势，应停止该分支并保留失败结果。首次完整临床确认失败以后，新修改是新方法，需要新的确认数据。

## 7. 样本量与统计假设：规则数量不等于独立信息量

### 7.1 完整诊断的配对比较

设两个冻结方法对同一独立病例的正确性不同的概率为q，目标正确率差为δ。双侧α=.05、功效.80的大样本无连续性校正规划近似：

n ≈ (z_.975 + z_.80)² × q / δ²。

| δ | q | 原始近似n | 向上取整 |
|---|---:|---:|---:|
| 3pp | .10 | 872.098 | 873 |
| 3pp | .15 | 1308.147 | 1309 |
| 3pp | .20 | 1744.195 | 1745 |
| 5pp | .20 | 627.910 | 628 |

这些不是保证功效的精确最小样本。q须由新开发pilot估计；正式方案以配对2×2分布模拟或精确McNemar功效确认，并预留预登记的不可评估病例比例。多个病例来自同来源/作者/疾病家族时，用聚类模拟重新规划；1+(m−1)ρ只能作初步膨胀近似，不能将所有rule actions视为病例。若比较多个方案，仅一个冻结主要比较用于主要声明，其他按分层检验/多重性校正，不能将每次p<.05当整项研究95%可靠。

### 7.2 抽取率与稀有硬错误

二项比例最保守p=.5时，95%区间半宽约5pp需约385个**独立规则机会**，仅用于工作量规划。来自同一表/窗口的叶子高度相关，应增加独立来源家族并用分层权重、家族bootstrap或设计方差；若设计效应约2，粗略需约770个规则机会，但不能用770个相同表叶子替代。关键复杂类型需单独精度目标，不能依靠原子多数掩盖组错误。

观察n个独立Bernoulli机会均无错误时，单侧95% Clopper–Pearson上界为 1−0.05^(1/n)：

| 希望上界低于 | 单个预登记终点，α=.05 | 两终点同时95%界的Bonferroni示例，每项α=.025 |
|---|---:|---:|
| 1% | n=299，上界0.996915% | 每项n=368 |
| 0.5% | n=598，上界0.499706% | 每项n=736 |

必须先确定独立单位和事件，例如“固定规则库在一个新病例上至少发生一次错误排除”。299个彼此相关的规则动作不能直接代入；同样不能把估算有效样本量塞入exact二项公式。条件动作精度可报告全部动作数及家族聚类区间，但零事件时普通cluster bootstrap会永远给零，**不能提供非零风险上界**。若要证明跨新来源家族的泛化，用独立家族事件终点或明确假设的稀有事件层次模型；病例风险和规则动作精度不是同一个概率。

共主门全部通过才晋级的intersection-union检验与“所有区间联合95%覆盖”是不同声明，不必机械混用Bonferroni；若要同时宣称多个风险/亚组上界，必须相应控制多重性。重复看数据、自适应增加样本和从coverage曲线上选最好点均另需预登记控制。对所有0错误不能只给“100%准确”。

## 8. 结果应如何交付及解释

每个阶段独立保存：冻结协议、来源/病例分割及哈希、原始输出与全失败记录、参考及分歧账本、逐规则映射、变换前后IR、每次修复证据、事实/连接、执行proof、完整/代理任务终点、成本、复算代码及运行环境。E00–E17各有独立目录，任何汇总数均能追到阶段与分母。

最终至少给出三组可互相冲突但都应保留的结论：

1. **源抽取能力边界**：何种规则F提高、D/O/H如何改变、哪些歧义/逻辑片段仍不支持，语法改善与源忠实改善分开。
2. **信息转化边界**：给定参考IR、参考事实、固定完整候选时的各自差额；保留合法硬规则的覆盖与错误风险，以及错误如何经过间接权重/L4/身份作用。
3. **任务增益边界**：全新自然病例上的完整答案和成本，proxy单列；若忠实度提高而旧MRR下降，先检查错误奖励被撤销、候选范围、病因/病灶角色和事实接口，不能自动把更忠实的方法判为无效，也不能因此免除临床验证。

路线的成功标准是把“为何成功或失败”变成可重复区分的条件，而不是预言某个表示可以零错误完成任意指南。只有源、患者、执行和完整任务四条证据链同时成立，才支持端到端改善的结论。
