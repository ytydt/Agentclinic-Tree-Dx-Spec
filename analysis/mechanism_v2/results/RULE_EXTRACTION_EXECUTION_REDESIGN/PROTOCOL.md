# 改进方案与研究路线的独立交付标准

本任务以本轮差量审计、前两次审计和文献原始证据为依据，提出可实施、可证伪的抽取器与执行器方案；不将提议冒充已经部署或已提高性能。

## 交付门槛

1. 每个改进可回指具体已知缺陷或文献方法；说明修补范围及未解决部分。
2. 提供 Rule/group 一等公民的数据契约：组级目标、效果、范围、出处与完整性；递归表达式、量词域与角色、否定、时序、阈值和计分分别有明确语义。
3. 抽取、审核/编译、事实绑定、逻辑求值、诊断动作及排名分层。未知不自动等于阴性，提及检查不等于阳性结果，父类不自动等于子类。
4. 方案包括借鉴研究的方法改造，不仅是继续添加关键词/关系门闸。
5. 给出阶段化路线、冻结对照、主要/次要终点、最小反事实及停止条件。11 例作开发回归；新确认实验和能力边界样本分开。
6. 明确成本、兼容/迁移、缓存版本、错误可追溯性以及源歧义的保留策略。合格的硬规则保留硬效力，错误/无法证明的硬规则不靠降权掩盖。

最终产物包含设计报告、迁移及实验矩阵、可审查的表示示例和验收向量。除审计工具外不修改现行生产引擎。
