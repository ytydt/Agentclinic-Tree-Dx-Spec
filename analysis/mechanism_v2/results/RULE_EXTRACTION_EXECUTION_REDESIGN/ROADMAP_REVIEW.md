# 研究路线的独立复核与修订记录

状态：2026-09-06 完成方案复核。这里复核的是研究设计及确定性规划计算，不是执行18项新实验，也不是临床专家盲审。

1. 独立统计复核校正了配对样本量的向上取整：3pp效应、discordance .10/.15/.20分别为873/1309/1745；5pp、.20为628。全部注明大样本无连续性校正规划近似，不称精确最小样本或保证功效。零事件单侧界及前一个n也由脚本检验。
2. 增加零事件聚类bootstrap的边界：观察全部零时重抽也全零，不能据此声称风险上界为零。病例事件、来源家族事件与规则动作精度分开；普通二项式上界不接受相关动作数或估计n_eff。
3. 主报告复核提出经典二值等价与K3运行等价的区别。路线及E02/E08/E12均增加logic_profile、完备性及conflict策略；A∨¬A与TRUE在A未知时不是K3等价。量词不完备域有足够见证或反例时仍可决定，不能一律unknown。源组结构未知与患者信息不全分开。
4. 独立方法快审发现G2可被“每源生成很多互斥猜测、至少一个正确”钻空子：原条件只要求召回提升、输出精度报告。已改为召回门与无冲突完整输出包F共主门同时通过，再要求输出忠实精度非劣、严格H及溯源未决不越预登记限值。边界由新开发pilot规划并在确认前冻结，没有从旧11例编造达标阈值。
5. 补充医学真值与question-target角色独立：真实并存病灶被确认不自动算假确认；若被错误当作互斥最终答案，另外计任务范围/角色违规。
