## 3. 二值等价与三值行为的可复现反例

用当前示例解释器的`eval_expr`分别计算`or(A,not(A))`和`literal(true)`，患者事实仅给A真、A假或不提供A；没有修改任何生产模块。

| A的输入信息 | `A OR NOT A` | 常量TRUE |
|---|---|---|
| 明确真 | TRUE | TRUE |
| 明确假 | TRUE | TRUE |
| 未观测 | UNKNOWN | TRUE |

前两行覆盖单个原子的全部二值赋值，因此经典等价检查可以通过；第三行显示该变换不保持本合同声明的未知传播。若据经典恒等式直接重写运行根式，就可能改变硬动作准入。这里不是说经典逻辑错误，而是证明与执行采用了不同语义。

主报告与协议现要求保留原IR作为运行参照，区分完整解释等价、三值行为等价及特定动作保持。二值求解器仍可产生完整世界中的区分反模型；它不能独自证明观察不完整时的运行行为。冲突政策和证明依据同样属于证书适用条件。该修订也防止CNF/DNF后端的“等价”标签掩盖逻辑profile变化。

## 4. 通过的语义检查与具体证据

- **方向与短路通过。** V35–V42、V47、V50及主文§4–5区分充分FALSE不排除、必要TRUE不确认、必要FALSE需授权；`FALSE AND UNKNOWN`与`TRUE OR UNKNOWN`可定根真值。未要求所有叶子均观测才执行。
- **共享事实与类别计数通过。** V18–V23按规定类别身份计数；V20允许同一fact来源的两个独立断言支持两个类别，未采用全局“每fact最多一次”。实际断言是否忠实于原始观察仍须事实桥接审定，向量不证明见证真实性。
- **开放域通过。** V12–V17保留完整域与观察列表差异：全称的明确反例和存在式的充分见证不要求先关闭全部域；V21–V23区分at-least与exact。完整空域的真仅是逻辑边界，另需临床适用范围。
- **缺源与缺观察分离通过。** V40阻止不完整源结构签发完整组结论；它不否认完整结构在未知观察下仍可获得合法短路结果。
- **派生规则继承通过。** 验证器静态检查必要合取的父引用、必要效果类型、子条件确为父合取项，以及target/applicability/provenance/completeness/authority继承。这里只实现这一种派生规则，不是一般证明检查器。
- **冲突策略已明示。** V45对无冲突真支路之外的冲突仍暂停，是演示的保守准入，不是逻辑强制；未用多数票或软分覆盖冲突。
- **权限真值层分离通过。** V43/V48/V54/V55区分元权限与`NOT(C→NOT D)`。`exclusion_permission`的外部作用域解析尚未实现，不能据flag测试声称完整权限解释器通过。

这组检查覆盖已声明的有限示例，不是对无限域一阶逻辑、全部未知/冲突策略或现实临床资料的穷尽证明。
