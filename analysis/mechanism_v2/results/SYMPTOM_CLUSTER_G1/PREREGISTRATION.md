## 0. 这道门在问什么，以及它为什么必须排在效应测量之前

计划 §0 已把问题陈述改写成：**集群信号是真实的，但它已经被生成器的置信度吸收了。**
生成序（转化率 0.560）强于任何可离线计算的证据派生信号（最好的 `n_high_groups` 只有 0.458），
而生成序 100% 由 commit 立场占据首位。所以集群只可能作为**改变生成器写出什么候选**的约束存在，
不可能作为更好的排序函数存在（Q9 已否证后者：组去重把转化率从 0.355 压到 0.307）。

干预因此必须动 commit 立场的 prompt。而 commit 立场正是**贡献了 144/166 独家捞回的那个立场**
（Q11）。multistance 相对全族唯一的存在理由是召回；把召回换成转化率不算成功，算换了个失败态。

**所以第一道门不是"有没有提升"，而是"有没有把已有的召回弄坏"。**

这道门的关键性质是它**零面板**。`ClinicalEndpoint` 以 `(case_key, canonical_label)` 为键，
对已知可达的病例我们已经知道**哪个具体标签**被冻结面板判为 `complete_equivalent`。
于是只需检查改动后的 commit 调用是否**仍然写出那个标签**。

这个测量是**单侧的、保守的**：

- 它能检出召回**损失**（冻结靶标签消失）。
- 它**检不出**召回**增益**（新写出的标签没有冻结判定，无法零调用判断其是否 complete）。

对一道保全门来说这正是要的形态：**门的职责是否决，不是确认。**
因此本预注册**不得**产出任何"干预有效"的结论；过门只意味着"允许去花 M1 的预算"。

## 3. 臂与 prompt（**执行前冻结，sha256 已固定**）

| 臂 | prompt 文件 | sha256 | 调用 |
|---|---|---|---:|
| `frozen` | `aphhm_c_batched_concepts_commit.txt` | `a28cdebd745b06cd…41ba2cf` | 0（复用冻结） |
| `arm_A` | `aphhm_c_batched_concepts_commit_cluster_a.txt` | `413ecba55c838b8c…3b3ebe` | 67 |
| `arm_B` | `aphhm_c_batched_concepts_commit_cluster_b.txt` | `38985920eff3e136…0333e6` | 67 |

两个干预 prompt 相对基线都是**纯插入、零删除**（`diff` 无 `<` 行），因此唯一变化就是干预本身。
基线 prompt 已经要求的东西（候选须由"对它而言不寻常"的发现驱动、support_spans 须挑能区分的、
须覆盖每条高特异性 fact、两候选不得同 spans）**一字未动**。

### 3.1 `arm_A`：不同相关组约束

对应计划 §3.1。靶向 Q1 测出的 **32.3% 候选 span 数（均 2.37）> 不同相关组数（均 1.95）**——
现有 prompt 说"不要把两个独立发现合并进一个 span"，但没说"不要给我三个同一发现的复述"。

插入两条规则 + JSON 增一字段 `observation_groups`：

- 每个候选的 support_spans 必须落在**至少 2 个互不重复的底层观察**上；同一观察的复述
  （同一皮损描述两次、检验值与其命名异常、症状与患者原话、发现与显示它的影像）算**一个**观察。
- 生成器须自报每条 span 属于哪个观察（`observation_groups`，与 `support_spans` 同序同长）。

**与 Q9 的关系必须写清：这不是 Q9 的重做。** Q9 在**冻结 payload 上做事后去重**，无法改变
"哪些候选被写出来"；`arm_A` 在**生成时**施加约束，能迫使生成器放弃只有单一观察支撑的候选。
两者作用对象不同，Q9 的否证不覆盖 `arm_A`。但 Q9 提供了一个悲观先验，§5 的预测须反映。

### 3.2 `arm_B`：合取作为被陈述的单位

对应计划 §3.2，是论文主张的直接操作化。现有 prompt 要的是每条 span **各自**支持该候选，
从未要求"这 2–3 条**合起来**才排除对手"。

插入一段 + JSON 增一字段 `conjunction`：指名 2–3 个发现的组合、指名最强对手的
`preferred_label`、写出该**组合**为何不能被该对手解释。

其中一条约束是本臂的判据核心：**"若删掉其中一个发现你的论证仍然成立，那你指的是单个判别
发现而非合取，须换一个组合。"** 没有这条，模型会把"最强的那一条 span"改写成一句合取话术，
本臂就退化成 `placebo_verbose`。

### 3.3 已放弃的干预 C（记录在案，不在本门内）

"按集群强度排序候选"**不做**。生成序 0.560 是涌现的，`n_high_groups` 排序只有 0.458，
显式指示等于用弱信号覆盖强信号（计划 §2.3／§3.3）。
若未来要检验，必须**单独预注册**且以"保住生成序"为硬门，不得夹在 A/B 里搭车。

## 4. 判据（执行前冻结）

### 4.1 主判据：冻结 complete 标签的保留率

对 67 例逐例配对，检查该例的 `retention_targets` 中是否**至少一个**仍出现在干预后的
候选集里（口径：`ClinicalEndpoint` 的 canonical label 匹配，与 Q11 同一 bridge）。

**门槛：保留率 ≥ 0.90，即 67 例中至少保住 61 例。**

这个门**不是统计检定，是工程容差**。它允许丢 6 例，作用是在花 M1 的预算之前挡住明显破坏
召回的 prompt。**它不声称能检出小幅召回损失**——67 例上 90% 的容差对应的检出力很低，
这一点必须随读数携带，不得把"过门"读成"召回未受损"。

### 4.2 次判据：候选集改变率

干预后候选集相对 `frozen` 发生变化的病例比例（口径：canonical label 集合不等）。

**若 < 0.15，判"无操作"而非"无害"。** 一个什么都没改变的 prompt 当然不会破坏召回，
但它也不可能在 M1 里产生效应，拿它去花 M1 的预算是浪费。

### 4.3 机制次判据与伪造防护

基线必须用**本队列口径**（dev + `c3:commit`，992 个带 `support_fact_ids` 的候选），
已随 [`cohort.json`](cohort.json) 的 `evidence_structure_baseline` 冻结：

| 量 | 本队列基线（dev + commit，n=992） | 可读性对照：Q6 全立场（n=3415） |
|---|---:|---:|
| 每候选不同 ledger 相关组数均值 | **2.1442** | 1.95 |
| 每候选 support_spans 数均值 | **2.5897** | 2.37 |
| span 数 > 组数的候选占比 | **0.3679** | 0.3233 |

**Q6 的 1.95 / 2.37 / 0.3233 不得用作本门的锚。** 它算在 3415 个候选、400 例、**全部立场**上；
本门只打 dev 的 commit 立场。这个差异足以**反转读数**：若 `arm_A` 给出 2.05，
对着 1.95 会读成"上升（约束已执行）"，而对着正确基线 2.1442 其实是**下降**。

#### 伪造防护（本轮新增，理由见 §4.5）

`arm_A` 的约束可以用两种方式满足，两者结果相反，必须分开测：

- **真执行**：放弃只有单一观察支撑的候选，去找支撑更宽的候选 → 我们要的。
- **交差**：把同一观察的复述**重新标注**成不同的 `observation_groups` → 自报数上升、
  实际证据宽度不变，纯噪声，且会骗过"均值是否上升"这一条。

两者用**两个独立的测量**区分。关键前提是 §2 已规定 facts 阶段**复用冻结产物、不重跑**，
因此两臂共享同一份 fact ledger，`correlation_group` 是与生成器自报**无关**的外部量：

| 测量 | 来源 | 性质 |
|---|---|---|
| `self_reported_groups` | `arm_A` 输出的 `observation_groups` 不同索引数 | 生成器的**主张** |
| `ledger_groups` | 候选 `support_fact_ids` 在冻结 fact ledger 上的不同 `correlation_group` 数 | **独立**测量 |

- **判据：`arm_A` 必须抬高 `ledger_groups` 均值（> 2.1442），不是只抬高 `self_reported_groups`。**
- `inflation = mean(self_reported_groups) − mean(ledger_groups)` 是伪造指标。
  基线上生成器不自报分组，故该量无基线；**`inflation` 显著为正而 `ledger_groups` 未升
  即判定为"交差"**，走 §4.4 第二行出口（prompt 未咬合，允许一次改写）。

`arm_B` 有同形风险：prompt 已要求 `conjunction.findings` "must report DIFFERENT
observations"。同法核验——findings 映射到的 `support_fact_ids` 须落在 **≥2 个**不同的
ledger `correlation_group` 上。合规率低即同样按"交差"处理。

#### 其余描述性次判据（不作判据）

- `arm_B` 的 `conjunction` 字段合规率：findings 逐字、≥2 条、对手已指名。
- "删一条仍成立"的自查是否真被执行：人读抽样 20 条。
- 池宽与均宽（防止干预以"多写候选"的方式虚假保住召回）。

### 4.5 为什么加这道伪造防护

这不是从 DA 实验的**结果**推来的（§7 禁止跨族合并结果），而是从它暴露的一条**机制**推来的：
[`DA_FINALS_AXIS_COMPLETION/REPORT.md`](../DA_FINALS_AXIS_COMPLETION/REPORT.md) §3.1／§4 实测到，
给生成器加一条硬性输出约束（"只准用三条表层轴"）会把它推向**交差**——在没有可补内容的病例上
也产出修饰词，使幻觉率从 SLOT_YIELD 同轴同口径的 0.0587 升到 **0.1583**；
而约束更松的那一臂反而弃权更多（125 vs 33）、幻觉率更低（0.1111）。

`arm_A` 的约束（"支撑必须落在 ≥2 个互不重复的观察上，否则砍掉该候选"）与之**同形**。
原判据只问"自报组数均值有没有上升"，而交差恰恰会让它上升。**没有这道防护，
`arm_A` 最可能的失败模式会被读成成功，并把 M1 的预算全部浪费掉。**

这道防护零调用、零额外预算，且在任何在线调用之前写入，因此不构成事后调门槛。

### 4.4 门的三种出口（冻结前写定，不得事后调整）

| 保留率 | 改变率 | 出口 |
|---|---|---|
| ≥ 0.90 | ≥ 0.15 | **过门**，进 M1（计划 §5.2） |
| ≥ 0.90 | < 0.15 | prompt 未咬合。允许**一次**改写并重跑，改写内容须在重跑前写入本文件；第二次仍 < 0.15 则**整线关闭** |
| < 0.90 | 任意 | **关闭该臂**。若 A/B 均不过，**整线关闭**，不再投入 |

## 5. 预注册预测

| 臂 | 保留率 | 改变率 | 依据 |
|---|---|---|---|
| `arm_A` | **≥ 0.90**（点估计 0.90–0.97） | **0.20–0.60** | 约束只要求"支撑更宽"，不要求换候选；但 32.3% 的候选当前违反该约束，故改变率不会太低 |
| `arm_B` | **0.85–0.97**（有实质风险不过门） | **0.30–0.70** | 要求写出合取论证会挤压 slot 预算与注意力，更可能改写候选集；这既是它的机会也是它的风险 |

**`arm_B` 比 `arm_A` 更可能不过门**，因为它对生成过程的干扰更大。若只有 `arm_A` 过门，
M1 就用 `arm_A`；这是预期结果之一，不是失败。

不作预测但必须记录：`arm_A` 的 **`ledger_groups`** 均值若**未**从 **2.1442** 上升
（注意锚不是 Q6 的 1.95，见 §4.3），则该臂即使过门也应按"约束未被执行／交差"处理，
进 §4.4 的第二行（允许一次改写）。

新增预测（§4.3 的伪造防护）：**`arm_A` 的 `self_reported_groups` 会比 `ledger_groups`
高 0.2–0.8。** 依据是 DA 实测的同形机制（§4.5）——硬约束优先被"交差"满足。
若 `inflation` 落在这个区间而 `ledger_groups` 未升，那就是交差，不是效应。

## 7. 可写与不可写（执行前冻结）

**可以写（无论结果）：**
- 保留率、改变率、相关组数均值、池宽，及其与基线的配对差。
- 干预 prompt 的 diff 与 sha256（已在 §3 冻结）。
- "整线关闭"这个结论本身——它与 Q3／Q4／Q5／Q9 的四条否证共同构成对
  `症状集群.md` 全部实现路径的完整否证记录。

**不可以写：**
- **不可把过门写成"集群干预有效"。** 本门零面板、单侧、只能检出召回损失（§0）。
  任何效应主张必须等 M1，且 M1 必须有 `placebo_verbose`。
- **不可把过门写成"召回未受损"。** 67 例 90% 容差的检出力很低（§4.1）。
- 不可把 `arm_A` 的结果外推到 `arm_B`，或反之：两者是不同干预，不是同一干预的两档。
- 不可把改变率读成效应量：改变率只区分"prompt 咬合了没有"。
- **不可与 DA 族 pooling。** 本门只在 MCR 执行。DA 的补全实验
  （[`DA_FINALS_AXIS_COMPLETION`](../DA_FINALS_AXIS_COMPLETION/PREREGISTRATION.md)）
  层不同、族不同、无共享调用。
- **不可动 holdout。** `mcr_200b` 的 86 例在本门中不得触碰；holdout 结果不得回流改门槛。
- 不可把 Q9 的否证当成 `arm_A` 的否证（§3.1），也不可把 Q9 的悲观先验当成不必测的理由。
- 不可把面板判定报成人工根真值；本门复用的冻结判定 truth tier 是 model-panel sensitivity。
- 不可在见到保留率后调整 §4 的任何门槛或队列。
