# 先解释被测量的“下降”和旧 7/11

本页由 `audit_endpoints.py` 与 `endpoint_and_rank_accounting.json` 支撑。冻结 11 例候选与结果，未增加候选，未将病例金标反写给诊断器。这是候选标签范围审核，不是新的临床专家判题。

## 两条索引对比必须分开

| 抽取提示词 | 旧索引 top-3 | v2 top-3 | 旧 MRR | v2 MRR | MRR 差 |
|---|---:|---:|---:|---:|---:|
| 旧提示词 | 7/11 | 6/11 | .427273 | .366667 | −.060606 |
| 新/free 提示词 | 6/11 | 4/11 | .413203 | .307143 | −.106061 |

`旧提示词/旧索引 → 新提示词/v2` 的 7→4 同时改变了提示词与索引，不能作为纯索引效应量。

旧提示词固定时，例 74 从历史代理 rank 1→4 的算术贡献是 −.068182 MRR，已经大于全部 11 例的净下降 −.060606；其余十例**净增 .007576**。具体为 773 下降、257/49/179 上升，其余名次不动。这不说明其余十例的推理变好：不动的结果可以换了一整套错误贡献，上升也可以源于错误淘汰竞争者。

新提示词固定时，同一 74 贡献 −.068182，另外十例净降 .037879：522、773、475 下降，257 上升。**这是 reciprocal-rank 的精确算术分解，不是错误原因的因果百分比分解。** 目标与竞争项分数、否决和确认存在交互；不能把删一条规则得到的 MRR 差简单相加。

## 旧索引的七个 top-3 到底命中了什么

| 病例 | 旧/旧名次与被接受标签 | 相对完整金标的地位 |
|---|---|---|
| 522 | 2，Catatonia | 组件；未表达因潜在 DLB 导致的关系 |
| 773 | 2，Patent Foramen Ovale | 组件；没有表达 IPAH with PFO |
| 119 | 1，Porokeratosis | 父类；缺少 EPPP 亚型 |
| 326 | 3，Brucellosis | 完整疾病标签 |
| 475 | 3，Neuralgic Amyotrophy | 完整疾病的同义名称 |
| 49 | 3，Appendiceal stump appendicitis | 完整疾病标签；这次提供第三名的不是泛化 Appendicitis |
| 74 | 1，CPVT 大写版本 | 完整疾病标签，但证据是否正确须另审 |

因此旧 7/11 包含 **4 个完整标签命中、3 个父类/组件命中**；不能称为七例完整诊断成功，也不能把四个完整标签命中说成四条医学推理链均正确。

按显式完整标签的保守口径，候选池只有 5/11 例提供完整标签：326、475、49、56、74。56 的 `Sarcomatoid squamous cell carcinoma` 明确在池内，却从未被历史 gold 集接受。这个标签四臂均无绑定证据，不能因为它在池里就说规则已经抵达金标。其他上下文相关的 sarcomatoid 标签未被本审计擅自升格为同义词。

四臂显式完整标签 top-3 分别为 **4/4/3/3**，完整标签 top-1 为 **1/1/0/0**。这些是输出名称范围的描述，**不称 clinical-complete accuracy**；候选缺失、源证据不足、基准题本身的可辨识性仍需另外判断。

## 不能忽略的指标伪变化

- 91 接受 Hemangioma 为 Angiosarcoma；这是错误实体，不是允许的父类模糊匹配。Hemangioma 四臂均无有效 join，零分 rank 6/5/6/5 不能视为恶性肿瘤诊断改善。
- 179 接受 manifestation-only 的 Thrombocytopenia，缺失 hypoxia 因果限定。
- 74 两个大小写重复标签共享临床身份却分别排名。**本次冻结 B1/S7 default-stale 的两个 v2 臂，有证据标签均在第 10，空重复标签均在第 4。** 先前报告文字中的“10/13”不能从这批 trace 得到支持，本轮以重放对象为准，不沿用 13。
- 排序键为“是否淘汰、确认条目数、分数”，不是简单按 score 排名。零证据节点仍可受竞争罚分；已淘汰节点仍有潜在软分，但不能和幸存节点只比数值大小。
