## 2. 审阅中发现并已在对应文本修正的问题

1. **326被过度归入“错误才保住top3”。** 原严格干预包含饮奶→羊胃这一暴露桥接。它不满足严格谓词，但粗动物产品暴露可能有合理弱支持价值。主报告现在并列核心敏感性：保留粗暴露时四臂top3都在，故不再以其作为无争议“错误必要性”见证。49等病例仍提供明确的取材对象错配见证，不需勉强所有病例符合一个故事。
2. **475引入不存在的痛后无力时序。** 原vignette只写急性/阵发无力，并未记录疼痛先于无力；主报告已改为急性起病和跨神经EMG分布。这是防止用疾病典型知识填补患者事实的重要校正。
3. **正向atomic mass被误译成分数“质量”。** 138.899等只含原子正票，不含组、确认及L4；现在明确为“正向原子票权重合计”。事实上最终候选分数正部合计old_old913.395→old_v2918.044略增，不能仅凭原子mass下降就说所有层次都无膨胀。
4. **旧CPVT错误共存被说成top1必要依赖。** 旧两臂单独释放QT/CPVT双门仍CPVT第一；单独阻断其选定错接也仍第一。主表已改为“混有/伴随错误”，不继续把共存当必要原因。v2双门释放LQTS第一、再去其QT错票CPVT第一，则提供不同的条件交互证据。
5. **例49组织学票数。** 四臂实际为6/6/7/6个去重predicate，旧/旧不是5；正文和主表已改“六至七”。+8.600总量原本正确。join-block后的目标分为7.649，已与numeric-only舍入结果区分。

## 3. “足以解释”必须保持在现有范围内

当前主报告把三种不同层次分开，因而可以回答用户的机制问题：

- **精确可重建的实际运行：** 每个分数和硬状态如何产生，端点变化由哪些病例贡献。
