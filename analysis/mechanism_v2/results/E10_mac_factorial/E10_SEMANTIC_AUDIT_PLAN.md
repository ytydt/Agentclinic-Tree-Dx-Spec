# E10 异族语义筛查与根审计计划

严格 frozen-synonym 终点可复现但可能漏掉临床可接受的表述。为提高人工审计的召回率，使用 `deepseek/deepseek-v4-flash-0731` 对 400 例中两种 history 的全部候选逐项做保守关系筛查。该调用获得 vignette、reference diagnosis 和候选标签，但不参与任何实验臂生成或聚合。

外部模型只充当分包筛查员：它的判断不直接改写端点。根审计队列无条件纳入所有严格 reference exposure、所有严格 Top-1/Top-2 或 exposure 分歧、筛查为等价/可接受/不确定的病例，并加入按 family、SHA 冻结的 20+20 个筛查阴性病例。最终临床等价性、轨迹方向、信息级联机制和错误责任均由根审计逐例裁决；同时报告筛查员在阴性抽样中的漏检，避免同一模型自证。
