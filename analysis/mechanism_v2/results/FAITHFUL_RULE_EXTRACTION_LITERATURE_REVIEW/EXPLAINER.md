# 这个目录在讲什么（面向初次阅读者）

共用术语见 [../READER_GUIDE.md](../READER_GUIDE.md)。本文只讲这个目录独有的东西。

## 一句话

「把指南文字变成可执行规则」这件事，外面已经做到什么程度了？调研的结论是：

> **嵌套逻辑、量词、否定、作用域，现有研究都能明确表达和执行；但没有任何一项证明能从任意临床指南里自动、零错误地把这些语义恢复出来。**

真正做成的系统，靠的都是**人工知识工程 + 受控表达 + 确定性编译 + 独立验证**的组合，不是单一模型。

## 最有价值的部分：拆穿了几个看起来很高的指标

这是本目录对本仓库最直接的贡献——**别人论文里的高分，很多测的不是我们需要的东西**。

| 别人报的数字 | 实际测的是什么 |
|---|---|
| LogicLLaMA「逻辑等价 LE = 0.924」 | 官方实现走的布尔向量路径**不解释量词前缀**。所以这**不是** 92.4% 的完整规则忠实率。 |
| Text2MDT「0.748」 | 那是**树组装子任务**的分数。真正的「完整决策树精确匹配」只有 **0.490**。 |
| FoVer「95.5%」 | 那是**单个查询**的正确率。要求一个样本的**全部**查询都对，严格口径掉到 **78.5%**。 |
| CPGPrompt「能抽指南规则」 | 全部生成的决策树都**经过人工验证**，测试病例又是**从这些树生成的**。而且官方节点仍是「字符串条件列表 + 阈值」，**明令禁止条件成员嵌套**。 |

这套「拆穿」的方法论本身值得复用：**看一个指标之前，先问它的分母和口径是什么。**

## 「准确」其实有六层，不能混为一谈

这是本目录提出的分层（作者说明这是本次综合，不是文献已有的统一等级）：

| 层 | 通过意味着 | 通过后**仍可能**怎么错 |
|---|---|---|
| 1 语法 | 括号、字段合法 | AND 写成 OR 一样合法 |
| 2 静态语义 | 类型、变量绑定、作用域合法 | mPAP 和 PASP 类型相同却不是同一测量 |
| 3 参考等价 | 和参考公式没有区分模型 | **参考公式本身可能就误读了原文** |
| 4 推导 | 结论确由输入推出 | 输入理论已经漏了限定、颠倒了必要性 |
| 5 **源文忠实** | 每个语义槽位和出处都对 | 病人观测仍可能没正确对应上 |
| 6 临床任务 | 完整诊断和病例相符 | 部分正确标签、错误互相抵消、评测器太宽松 |

**本仓库真正缺的是第 5 层**，而大多数文献工作加强的是第 1、2、4 层。

作者由此提出一条对本仓的直接告诫：不能再用「抽了多少行」「求解器跑得通」「11 例 MRR 多少」来代替能力边界的度量。

## 需要解释的专用说法

| 说法 | 平实解释 |
|---|---|
| **FOL（一阶逻辑）** | 带变量和量词（「所有」「存在」）的逻辑。日常说的「嵌套逻辑」大多在这个范围内，**不需要动用二阶逻辑**。 |
| **受控语言（ACE 等）** | 一种受限的英语子集，写出来像自然语言，但每个句子的逻辑含义是唯一确定的。 |
| **DRS / MRS** | 两种语义表示法。MRS 的特点是可以**先保留作用域不确定**，等信息够了再定——很适合处理指南里那些含糊的嵌套。 |
| **约束解码（PICARD / Synchromesh）** | 在模型逐字生成的过程中就挡掉不合法的输出，而不是生成完再检查。 |
| **反解释 / 反模型** | 构造一个具体情形，让两个公式的真值不同，以此证明它们不等价。 |
| **开放世界 vs 封闭世界（OWL vs SHACL）** | 前者认为「没记录」≠「不存在」，后者用来检查数据是否合规。**语义完全不同，换后端解决不了问题。** |
| **CQL 的 `AllTrue` 陷阱** | 这个函数**忽略空值**：空列表、全是 null 的列表、null 列表，统统返回真。直接拿它实现「所有成员都满足」会把「没测」当成「满足」。 |

## 调研范围与诚实边界

- 共 **35 个研究/标准条目**，分四类：现代 NL→FOL 11 项、组合语义与语义解析 9 项、临床 LLM 方法 8 项、经典临床语言与标准 7 组。
- **一个条目可能包含论文加官方规范，不能读成「35 篇独立实验论文」。**
- 这是**围绕已观察到的失效机制做的定向调研**，不是穷尽式系统综述，也不是效果元分析。
- 只做了**静态审读**：没有安装运行外部系统、没有复现论文准确率、没有新的模型调用。
- TSDTE 没拿到全文，GLIF3 只用了摘要——这些限制都逐项保留在账本里。

## 结论落到本仓库是什么

最值得借鉴的不是某种输出格式，而是这个**组合**：

1. 先建立**有原文锚点**的规则、概念和逻辑依赖；
2. 再用**受约束的编译**检查结构；
3. 针对容易混淆的读法**生成反模型**；
4. 把患者事实和「推断权限」**分开审查**；
5. 最后按**完整规则**执行一次。

作者明确标注：这是一条由审计和文献支持的**设计推论**，**尚未证明能在本仓库提高性能**。
