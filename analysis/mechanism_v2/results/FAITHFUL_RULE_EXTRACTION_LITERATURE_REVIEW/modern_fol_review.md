# 现代 NL→FOL 抽取、神经符号验证与评测边界

检索/访问日期：2026-09-05 至 2026-09-06。范围：11 篇直接相关原始研究，覆盖 2023–2026；以正式论文为准，尚以预印本公开者锁定版本。阅读方法、实验、错误分析及官方实现，不依据标题中的 “faithful”“verification” 推断保证。本文是任务二的现代 FOL 分报告；临床指南表示与经典语义解析由同目录其他分报告覆盖。本文不改动生产代码，也未运行这些外部项目。

## 1. 直接回答本仓库的问题

**这些研究提供了比“原子行 + group_id + quantifier”更强的表达和审查方法，但没有证明可对任意指南散文零错误地恢复谓词、连词、量词、方向及作用域。** 最有直接迁移价值的是 CLOVER 的组合分解与反解释、带可信参考公式的等价检验、源文在场的可回退修复，以及显式符号表。最危险的误读则是把可执行率、结论准确率或宽松的 “逻辑等价分数” 当作源文忠实率。[CLOVER §3](https://arxiv.org/html/2410.08047v2)、[Logic-LM++ §3–4](https://aclanthology.org/2024.nlrse-1.6.pdf)、[FOLIO §5](https://aclanthology.org/2024.emnlp-main.1229.pdf)

下表是本审阅对保证边界的归纳，而非任何论文提出的统一分级。

| 验证对象 | 成功实际说明什么 | 仍可能漏掉的本仓错误 |
|---|---|---|
| 字符串/AST 语法合法 | 能被解析 | AND/OR 选错；把必要条件写成充分条件 |
| 类型、元数、变量闭合合法 | 公式在给定签名内成立 | 把 PASP 绑定到 mPAP；把 IgA 绑定到 IgG；域选错 |
| 两个公式在固定签名、符号映射及背景理论下等价 | 求解器证明二者无区分模型 | 参考公式本身错、谓词语义对齐错、原文缺失 |
| 从公式证明结论 | 结论遵循输入理论 | 理论不是原文；加入未声明常识；只忠实于被截断的半组 |
| 原文→完整规则忠实 | 需可信源文、结构/范围/模态及遗漏审定 | 本文所审自动方法均未消除人工或语义模型的不确定性 |
| 病例诊断排序正确 | 一个下游任务终点正确 | 碰巧答对、上位类计为金标、错误互相抵消、零票行改变其他票权 |

LINC 和 Logic-LM 将推导交给求解器，主要加强上表第四层。CLOVER 更接近检查第三层与第五层之间的桥，但对“反解释是否符合自然语言”的裁决仍由 LLM 完成。[LINC §2](https://aclanthology.org/2023.emnlp-main.313.pdf)、[Logic-LM §3](https://aclanthology.org/2023.findings-emnlp.248.pdf)、[CLOVER §3.3](https://arxiv.org/html/2410.08047v2)

## 3. 最需要深入借鉴与审慎处理的四条路径

### 3.1 组合结构必须保留；“写成 FOL”本身不会补回语义

CLOVER 的关键是先建立逻辑依赖结构，再将组成单元逐步译成多类型 FOL。其 coupler 不只包含 AND/OR，也处理多个描述共享论元的合并；量词与否定作为依赖成分随组合保留。随后对多候选公式进行逻辑等价聚类，求两候选互不蕴涵方向的反解释，再询问模型反解释是否满足原句。[CLOVER §3.1–3.3](https://arxiv.org/html/2410.08047v2)

但 CLOVER 在逐句形式化之前，也先由 LLM 从整题生成估计理论及目标自然语言句集；反解释核验针对的是这一整理后的目标句。若源文限定已在这一步遗漏，后续求解器不能据此恢复原文完整性。[CLOVER §2、式 2–3](https://arxiv.org/html/2410.08047v2)

本仓迁移推论：这比在每个原子行末尾补一个 group_id 更接近真正的组抽取。它能把“所有 κ 或所有 λ”和“每项 κ 或 λ”作为不同结构送去检验，但仍有三个源侧前提：成员全集已可见、共享变量/域判定正确、生成候选中包含可信读法。对一个被截掉一半的诊断表，求解器可以完全正确地验证一个不完整公式。等价聚类也无法排除所有候选共享的同一误读。

原文语义树与执行范式必须区别：Logic-LM 的 Prover9 路径由求解器侧转换 CNF，而非依赖模型直接写出规范 CNF。[Logic-LM §3.2](https://aclanthology.org/2023.findings-emnlp.248.pdf) 因此本审阅推论是：CNF/DNF 可用作确定性编译与审查视图；不能以“输出已经是 CNF”替代原句对齐。多层 AND/OR、否定、对象量词仍属一阶表示；只有对谓词/关系本身量化才涉及真正的高阶逻辑。不能把嵌套深度当作必须采用高阶证明器的理由。

### 3.2 逻辑等价指标也可能漏掉量词：LogicLLaMA 的代码级反例

官方 `metrics.py::compute_LE` 调用 `VecRuleEvaluator.find_best_LE_score`，启用软绑定、贪心匹配；`fol_parser.py::from_nltk_tree` 遇到 `S` 节点仅递归最后的公式子树。后续计算的是原子文字对应的布尔向量，未解释量词前缀。[metrics.py](https://github.com/gblackout/LogicLLaMA/blob/785a2c08e8fe964c8b2a10bb183ce5a08867aa3b/metrics.py)、[fol_parser.py](https://github.com/gblackout/LogicLLaMA/blob/785a2c08e8fe964c8b2a10bb183ce5a08867aa3b/fol_parser.py)

**这是静态源码核验，不是本轮复跑该外部项目的结果。** 由该实现可推得：仅把同一公式体前的 ∀ 改成 ∃，这一布尔评价路径不能识别其量词差异。例如在两元素域中，一个对象满足 P 而另一个不满足 P，`∀x P(x)` 与 `∃x P(x)` 可有相反真值；只比较公式体的原子真值表却失去这一差别。故把 LE=0.924 解读为 92.4% 的量词、作用域或完整规则正确率是不成立的。

更强的参考等价路线是将 `¬(φ ↔ ψ)` 交给求解器；在签名、谓词含义及参考 φ 已可信的前提下，证明不可满足才是等价证据。Vossel 等采用这一方向，但还包含谓词名字后匹配与超时限制。[评测 §3.5](https://arxiv.org/html/2509.22338v2) 本仓的 mPAP/PASP、IgA/IgG 刚好说明：即使字符串很像，也不能先宽松对齐谓词再声称形式等价。无法决定、超时、原文歧义与已证明不等价必须分开记账。

### 3.3 修复需要源文与回退，但语义裁判本身仍需被审计

Logic-LM++ 的实例直接展示：一次成功的语法修复可以把“不存在教书的年轻人”改成“所有年轻人都教书”。其改进是将原题重新置于修复上下文，并让模型比较两个公式版本，以拒绝语义退化的修改。[Figure 1–2、§3.2–3.3](https://aclanthology.org/2024.nlrse-1.6.pdf)

对本仓的推论：不能只在 JSON 失败、元数失败、solver error 时启动修复。排除极性反转或把病理特征升级成独立确诊往往完全可执行。源句、修复前后结构差及最小反例比“检查你的答案”更具体。但同一模型可能坚持同一医学误读，比较两个错误公式也可能选出较顺口者；因此回退应作为降低风险的可测干预，不能被命名为已通过忠实性证明。

CLOVER 的反解释比无具体世界的两段评论更有判别信息，但其自然语言裁决仍是模型判断。真实硬规则的授权还需要核查原句是否表示必要、充分、排除、概率关联或仅建议检查；形式上的 `A→B` 正确不等于引擎可以把它升格为临床否决。[CLOVER §3.3](https://arxiv.org/html/2410.08047v2)

### 3.4 谓词身份、背景知识与形式结构是三个不同误差源

Vossel 等的给定谓词与预测谓词实验，使“识别临床实体/属性”和“组合逻辑结构”可分别观察；其结果也提醒不能预设两阶段自动优于一次生成。[§4](https://arxiv.org/html/2509.22338v2) MenTaL 则跨句维护同一语义概念的符号，针对语言变化造成的符号漂移。[§4–5](https://arxiv.org/html/2506.04575v3) 本仓对应的未解决问题是双向的：同义实体被拆开固然错误，父类、近邻指标或不同标本结果被合并也同样错误。SDS 低只覆盖前者；所有疾病都误用同一符号也不能因此称为忠实。

NL2FOL 的 NLI 背景蕴涵、FoVer 的可选常识都允许补充字面之外的信息，这是其任务需要，而不是“从源文抽取”的同义词。[NL2FOL 方法](https://aclanthology.org/2025.findings-ijcnlp.8.pdf)、[FoVer §3](https://aclanthology.org/2025.tacl-1.61.pdf) 本仓可以借鉴显式分层，却不能把补出的临床常识标为指南原句，更不能把一条背景桥接当成新增高置信硬规则。FoVer 延迟声明量词的编程约定降低某类构造错误，也没有替模型决定正确的量词顺序和作用域。

FoVer 的验证过程还会改变待验证理论：Algorithm 1 对冲突的辅助定义取得 unsat core，并删除其中的定义，再检查保留理论。该处理不是对原始全部定义的忠实性证明，迁移时必须保留删除记录，也不能仅据该伪代码声称得到了最大保真子集。其 FOLIO 70.4% 还使用统一 Entity sort 的专用提示；通用提示无常识条件为 62.1%，两种表示条件应分开。[FoVer §3.3 Algorithm 1、§5.2 Table 3](https://aclanthology.org/2025.tacl-1.61.pdf)

### 3.5 一个结论答对会高估整个形式化包的质量

FoVer 的额外实验特别贴近本仓问题：同一 ProofWriter 样本包含约 10–20 个问题，其 GPT-4o 无常识条件报告单查询 95.5%，要求全部结论正确的 strict 设置为 78.5%。两设置执行率也不同（97.0% 与 98.5%）；论文未建立同一缓存公式只改判分的控制，故不能把差值视为单独改变评分口径的因果效应。另有把原 Unknown 标签下的 True/False 接受为正确的 relaxed 口径，不能把其中的 100% 条件准确率当作零错误抽取。[FoVer §5.1、Table 2](https://aclanthology.org/2025.tacl-1.61.pdf)

本仓迁移推论是：每条组公式至少需要覆盖多个能区分读法的输入状态；只复算当前 vignette 是否推到一个金标，会让与该结论无关的漏项、错误方向或不必要前提全部漏检。多个查询仍只是有限行为测试，也不等于对原文全部含义的证明，但能直接暴露单题终点所掩盖的缺陷。

## 5. 从这些论文不能直接推出什么

1. **不能推出“形式化一定优于无 RAG/无求解器”。** LINC、FoVer、NL2FOL 与反事实稳健性研究都有受任务/模型影响的反向结果，见第 2 节。形式化是可审计性的机会，不是净性能收益的证明。
2. **不能从短篇前提—结论任务估计指南抽取召回率。** 给定结论的 FOLIO 与给定论证的 NL2FOL 不需要遍历指南发现“有哪些独立规则”，也不直接测漏抽与无来源新增。它们可测一部分翻译能力，不能填本仓 faithful/distorted/omitted/hallucinated 的分母。
3. **不能从一个标签正确推断全部公式正确。** 许多错误前提可能不参与当前证明；缺一个成员也可能不影响这一结论。本仓旧索引 7/11 与代理金标更进一步要求独立的内容忠实终点。
4. **不能把自然语言模糊模态硬化为全称规则。** “常见”“提示”“建议排查”“通常需要”是否适合刚性蕴涵，是源文语义与决策授权问题，不是括号或量词符号能自动解决。
5. **不能把求解器 unknown 当作临床排除。** 它可能反映不足以证明、逻辑片段限制、超时或表示错误；临床资料未报告也不等于否定。LINC 保留三值结论是有用参照，但其源翻译仍不完整。[LINC §5](https://aclanthology.org/2023.emnlp-main.313.pdf)

上述 2–4 项是将研究任务定义与本仓审计对象对照后的推论，不是对论文未做医学实验的指责。

## 6. 可迁移方法的证据强度与下一步判别问题

本节仅界定任务三应处理的研究问题，不实施设计或预报收益。

- **直接优先检验：组合分解 + 固定签名的参考等价/反模型。** 有 CLOVER 机制与 Vossel 等直接公式评测支持；但应先在本仓人工核验的原子及组合规则上测量，而不是先用 11 题 MRR 选提示词。
- **作为受控修复臂：源文在场 + 局部差异 + 回退。** Logic-LM++ 提供明确机制实例和模型依赖的实验结果。必须同时统计修对、修坏、未改与从一种错改成另一种错。
- **作为身份消融：自由谓词 / 人工固定谓词 / 人工固定完整结构。** 分开识别概念绑定与逻辑组合上界；不能把 oracle 谓词条件的提升写成可部署提升。
- **作为鲁棒性测试：保义改写与反义最小对共同使用。** 借鉴 SoLT 及 ALTA 反事实实验，但既要对同义/顺序变化保持结果，也要对 all→any、正→负、mPAP→PASP 等真正语义变化作正确响应。只测不变性会奖励不看输入的模型。
- **作为审计基础：源显式、定义、推导桥接分列。** FoVer/NL2FOL 的背景通道可以借鉴；源支持不足时不应伪装为引用充分。对无来源新增仍需独立分母和原文搜索记录。
- **暂不能直接采用的成功指标：LE、可执行率、SDS 或 NLI 标签单独作忠实度。** 每项可保留为局部指标，同时要求源跨度、全组覆盖、论元/身份/极性/域/作用域和执行效应的独立审定。

理想的模型也不能修复一个不允许表达正确结构的 schema；完美 AST 也不能修复执行器将单叶满足当整组满足。这两层应由独立测试证明，否则“抽取器变好”仍可能沿错误执行通路放大伤害。

## 7. 可复核性、版本与代码状态

完整来源字段见 [modern_fol_sources.json](modern_fol_sources.json)，检索和访问路线见 [modern_fol_search_log.json](modern_fol_search_log.json)。

- FOLIO 版本不可混用：LINC 使用历史 204 例删去 22 后的 182；Logic-LM/Logic-LM++ 及 ALTA 研究采用历史 204；正式 FOLIO 论文的 validation 为 203。不同论文的同名列不是同一冻结测试集。[FOLIO 官方数据](https://github.com/Yale-LILY/FOLIO)
- LogicLLaMA 论文中最终 MALLS 为约 28K；官方 README 还保留过往规模描述，不能把不同数据版本拼成一个训练量。Vossel 等仓库当前说明涉及后续 GROVES，本文数字仅取其 2025 v2 论文。[LogicLLaMA](https://github.com/gblackout/LogicLLaMA)、[Vossel 等代码](https://github.com/fvossel/ANLFtFOLwFLLMs)
- 十篇研究的官方仓库/数据仓库可查阅；Logic-LM++ 的正式论文和针对作者/项目的检索未定位官方代码。这里的“未定位”不证明世界上不存在。MenTaL 的论文官方仓库地址发生重定向，实际目标已记录。
- 本轮进行了论文阅读与指定实现的静态检查，没有安装/运行外部项目，也没有复现上述论文准确率。代码可访问不等于全部权重、供应商模型快照及依赖均可复现。
- CLOVER 的 arXiv v3 HTML 请求不可用，改读可用 v2 与 ICLR 记录；没有用失败页面或搜索片段补造方法。检索也发现若干更新但未完成全文审查的工作，记录为未纳入，未据此作结论。
