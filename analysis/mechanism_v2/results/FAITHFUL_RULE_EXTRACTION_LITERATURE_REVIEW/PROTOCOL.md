# 文献调研的独立交付标准

检索将在新旧索引差量审计主要证据及干预完成后开始。调研对象是文本到忠实且可执行的知识表示，不预设 JSON、知识图谱、Python 或树形结构天然正确。

## 需要回答的问题

1. 哪些方法直接抽取 FOL，如何处理变量、量词域、否定、作用域、蕴涵方向、递归布尔表达式？哪些只处理命题逻辑或封闭合成数据？
2. 受控自然语言、语法约束、类型检查、证明器/求解器、反模型、round-trip、源证据对齐分别保证什么，不能保证什么？
3. 临床指南形式化、CPG 树、可执行规则、知识图谱和程序方法如何区分诊断、建议、评分与工作流？如何处理不完整病例、时序、异常、范围与冲突？
4. 论文结果究竟测公式等价、槽位准确、有效语法、可解率还是最终问答准确率？是否有人类专家语义审定、独立数据、公开代码和可重现输入？
5. 哪些思路可迁移到本仓库的实际失效机制，迁移需要哪些额外适配和验证？

## 产物与验收

- 原始论文及官方实现为核心来源；保留检索日期、检索式、纳入理由、精确出处。
- 至少分别覆盖通用形式化、语义解析与约束/验证、临床指南表示三条研究线。
- 对直接相关研究制作方法—表示—监督/验证—评测终点—限制—可迁移部件对照表。
- 不把求解正确等同于翻译正确；不把嵌套布尔/FOL称为高阶逻辑；不声称任何方法保证任意医学散文零错误。
- 若某一精确项目（如 CPGPrompt）的完整文本/实现不可获取，明确记录可核验范围，不根据标题补造机制。
- 保留详细研究矩阵与综合报告，和任务一、任务三各自分目录。
