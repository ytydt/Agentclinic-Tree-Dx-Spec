配对量的移动是显著的：`d = n_for(C) − n_for(W)` 均值从 −1.56 移到 −0.59，逐例看 34 例利好正确候选、13 例反向、16 例不变，精确符号检验 **p = 0.0031**。对称后 `d < 0` 的 28/63 已低于 31.5 的偶然水平，即支持侧的不对称基本消失。

## 机制：被夸大的是冠军，不是被饿死的正确候选

这是本门最有信息量的读数。不对称的收窄几乎全部来自**冠军一侧缩水**，而非正确候选一侧变强：

| | 冻结 | 对称重推 | Δ |
|---|---|---|---|
| 正确候选 `for` 均数 | 2.29 | 2.22 | −0.07 |
| 冠军 `for` 均数 | 3.84 | **2.81** | **−1.03** |

而缩水量按 payload 位置分层后高度集中：

| 冠军所在位置 | n | 冻结 `for` 均数 | 对称 | Δ |
|---|---|---|---|---|
| 位置 0 | 44 | 3.93 | 2.68 | **−1.25** |
| 位置 > 0 | 19 | 3.63 | 3.11 | −0.53 |

冻结分布也印证这一点：冠军的 `for` 计数偏高（≥3 的有 46/63，其中 12 例达到 5，超出 stance prompt 自称的 "1-4 spans" 上限），正确候选偏低（≤2 的有 39/63）。对称重推把两侧都压回 2–3 区间。

结论是：stance 调用**系统性地给它首先提出的候选堆砌支持 span**。这与 `aphhm_c_batched_concepts_commit.txt` 的契约直接相关——它在一趟调用里既提候选又写证据，且硬性要求"两个候选不能有相同的 support_spans"，于是最先被写下的候选优先占用了那些可共享的发现，后来者只能拿到剩余的、更弱的 span。比较器随后忠实地"权衡 for 与 against"，就被这个次序性偏置带走。

这也回填解释了 `MCR_SELECTION_LAYER_AUDIT` 的 Q3：比较器与 payload 位置 0 的一致率 77.8%，此前只能记为"位置先验"，现在有了因果路径——位置 0 的候选**确实**在 payload 里看起来证据最足，因为它的证据是被优先分配的。

## 反对侧只是部分假象（G-B fail）

`against` 侧的不对称更顽固：C 有反对而 W 干净的例数只从 21 降到 16，未达 ≤12。绝对量上 C 的 `against` 均数仍高于 W。合理解读是这一侧混入了真实信号——本队列的正确答案多为罕见病/非典型表现，vignette 里确实存在它解释不了的发现。因此完整干预不应预期把 `against` 侧的不对称也抹平，也不应把抹平它当作目标。

## dev / holdout 一致性：方向一致，holdout 更弱

| | n | C 更少（冻结 → 对称） | 均数差（冻结 → 对称） |
|---|---|---|---|
| dev（mcr_v1 + v2） | 26 | 20 → **8** | 1.38 → **0.19** |
| holdout（mcr_200b） | 37 | 28 → **20** | 1.68 → **0.86** |

两侧同向，但幅度差异明显：holdout 单独看，G-A 的均数差一项（0.86）达不到 0.60 的阈值，只有计数一项达成（20/37 = 54%，冻结为 76%）。预注册明确规定本门在合并的 63 例上判定、不分阶段，因此 PASS 成立；但这条不一致必须带进完整干预的预期——**合并样本的 0.59 是贴线通过，且靠 dev 拉低**，不应按 dev 的幅度去外推收益。

## 这个结果不说明什么

- **不说明转化率会提升。** 本门未重跑选择器、未产生新冠军、未测任何 complete/task 端点。证据不对称是假象，不等于修好证据后比较器就会改选正确候选——它还要求比较器对新的、更平的证据分布做出不同决策，而审计 Q3 显示比较器有 77.8% 的位置顺从性，位置在本门中并未改变。
- **不说明证据总量该增加。** 对称重推让冠军侧下降、正确侧基本不动，净效果是总量下降。若完整干预的目标被误设为"给正确候选写更多证据"，方向就错了；目标应是**去掉次序性偏置**。

## 下一步

需要在预注册中先固定的两件事：一是 dev 的放行阈值（考虑到本门 holdout 幅度较弱，阈值不宜按 dev 幅度设定）；二是共同抬升/压低的风险读数——本门显示对称重推使证据总量下降，需预先规定 C∪P 的保护门，防止比较器在更平的证据下退向更粗的标签（截断实验已观察到这种退让形态）。

**本门的 PASS 结论未被推翻**：不对称的确主要是写法产物。被推翻的是它的可利用性——完整干预
