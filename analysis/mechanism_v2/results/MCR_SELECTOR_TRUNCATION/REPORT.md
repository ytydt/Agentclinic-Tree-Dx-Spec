# MCR 选择层候选截断：**NO_GO**，且主假设被证伪而非仅"未测出"

实验 ID：`MCR_SELECTOR_TRUNCATION_V1`
执行日期：2026-08-21
预注册：[`PREREGISTRATION.md`](PREREGISTRATION.md)（含执行 G1 后的修订 A）
装置：`analysis/mechanism_v2/mcr_selector_truncation.py`、`analysis/mechanism_v2/mcr_truncation_score.py`
调用：**495 次**（预算 495，一次不多），其中面板 0、task 投射 0。

## 1. 结论

**截断比较器的候选集合不能改善 MCR 的诊断完整性；它略微有害，且越窄越差。**

主对比 `group5` − `frozen` 在 clinical-complete 上是 **−2 例**（p = 0.754，Holm 校正后 1.0）。
预注册预测的是 **+10 至 +30 例**（条件转化 +6pp 至 +18pp）。方向相反、量级相差一个数量级。

**而且这不是"样本不足所以没测出"。** 关键的证伪证据与面板准确率无关：

> 删掉平均 8.54 个候选中的 3.54 个，**冠军只在 15/167（9.0%）例上发生了变化**。
> 这是一个机械计数，不经过任何临床判定。一个只改变 9% 输出的干预，
> 无论用什么尺子去量，都不可能产生预测的 +6pp 至 +18pp。

配对不一致对总共只有 **10 对**（6 比 4）。预测的 +10 例增益要求至少 10 对**单向**不一致；
观测到的不一致**总量**就是 10 对且双向分裂。所以预测被不一致对的**体量**排除，
不只是被符号排除。

## 3. 三个对比

| 对比 | base only | test only | Δ 例 | Δpp/400 | p（精确 McNemar） | Holm |
|---|---:|---:|---:|---:|---:|---:|
| **`group5` − `frozen`**（纯宽度，主假设） | 6 | 4 | **−2** | −0.50 | **0.754** | 1.0 |
| `flat5` − `group5`（框架 + 两步退化） | 0 | 1 | +1 | +0.25 | 1.000 | 1.0 |
| `flat3` − `flat5`（剂量） | 8 | 4 | −4 | −1.00 | 0.388 | — |
| `flat3` − `frozen`（剂量，对参照） | 9 | 4 | −5 | −1.25 | 0.267 | — |

**主假设 NO_GO**（Go 门槛要求 `group5` ≥ `frozen` 且 p < 0.05；实测方向为负）。
**框架效应为零**：把 stance 分组换成单一伪组、并让 prompt 的两步决策退化为一步，
只改变 1 例。所以分组框架在这一层既不是负担也不是助力。

**剂量单调向坏**：越窄，冠军被扰动得越多（9.0% → 9.6% → 12.6%），净效应越负（−2 / −1 / −5）。
如果候选干扰是真的，这条曲线应该朝相反方向走。

次端点全部为零：C∪P Δ = +1（p = 1.0）、legacy `dc.match` Δ = +2（p = 0.688）、
task Δ = +2（p = 0.500）。预注册的敏感性分析（`uncertain` 当失败 vs 剔除）**逐位相同**——
四个臂没有任何一例冠军落在 `uncertain` 上。

## 4. 机制：尾部候选并没有在干扰比较器，比较器本来就在忽略它们

这是本实验真正的产出。把 `group5` 拆开看：

| 量 | 值 |
|---|---:|
| 冠军发生变化 | **15 / 167（9.0%）** |
| 冻结失败的 63 例中，slate 仍保留完整标签（可救上限） | 50 |
| ⤷ 其中冠军变了 | 9 |
| ⤷ **其中真被救回** | **4 → 兑现率 8.0%** |
| 冻结已成功的 104 例中，冠军变了 | 6 |
| ⤷ 其中变坏 | **6（6/6）** |
| 净 | **−2** |

两条读数：

1. **可救的 50 例里只兑现了 4 例（8%）。** 预注册假设"完整标签留在 slate 里 + 干扰项被删除"
   就能让比较器改选它。实际上这 50 例里有 41 例连冠军都没变——**完整标签就在更短的名单上，
   比较器仍然选了别的**。位置 5 之后那些 P(complete) 只有 0.006–0.036 的候选，
   删掉它们对决策几乎没有影响，因为比较器原本就没在认真考虑它们。
2. **扰动是近似对称的噪声，不是系统性改善。** 失败例里冠军变了 9 例、救回 4 例（44%）；
   成功例里冠军变了 6 例、**全部 6 例变坏**（100%）。两个方向的"改主意"数量相当，
   而在已经答对的病例上改主意必然是损失。

### 4.1 变坏的方式不是"丢了正确候选"，而是"退向更粗的父类"

6 例变坏中 **5 例的冻结冠军仍然在 `group5` 的 slate 里**（只有 1 例是被截断真的删掉了）。
比较器是在看得见正确答案的情况下改选了它的父类：

```
mcr_200b/296  gold=Sweet's syndrome
              Sweet syndrome                 -> Neutrophilic dermatosis      [partial]  原冠军在
mcr_v1 / 22   gold=adenomatoid tumor
              Adenomatoid tumor              -> Epididymal tumor             [partial]  原冠军在
mcr_v2 /235   gold=Nonketotic hyperglycemia hemichorea
              Hyperglycemic Hemichorea       -> Hemichorea-Hemiballismus     [partial]  原冠军在
mcr_200b/340  gold=retropharyngeal calcific tendinitis
              Retropharyngeal calcific tend. -> Calcific Tendinitis          [partial]  原冠军被截掉
```

关系迁移矩阵（`group5`，12 例端点关系发生变化）：

| 迁移 | 例数 |
|---|---:|
| complete → partial（退向粗父类） | **4** |
| complete → 真错（conflict / not_eq） | 2 |
| not_eq / manifest / conflict → complete（救回） | 4 |
| 其它 | 2 |

**"完整 → partial" 是变坏的主形态。** 这解释了为什么 C∪P 几乎不动（+1）而 complete 下降：
损失基本发生在 C∪P **内部**，即冠军仍然"对但更粗"。

一个可检验的解释是 tournament prompt 自己的规则："若一个 finalist 命名亚型、另一个命名其家族，
只有当 vignette 确实确立了亚型时才选亚型，否则选家族。" slate 变窄之后，
"亚型 vs 家族"这一对在名单里的相对显著性上升，把决策推向家族。
`flat3` 上 complete → 真错从 2 例升到 5 例，与"越窄越退让"一致。
**但本实验没有直接操纵这条规则，所以这只是与数据相容的解释，不是已确证的机制**；
要确证须另设一臂改写该条规则。

## 5. 与 E5 的和解：斜率不反向，而这正是 E5 自己的结论

预注册的预测 2 建立在把 E5 的 MCR **−6.33pp/候选**反向外推上，并在 §6 明写这是
"假设而非实测"的最薄一环。**它就在这里断了。** 两者不矛盾，原因是 E5 测的是别的东西：

| | E5 | 本实验 |
|---|---|---|
| 方向 | **加**候选 | **删**候选 |
| 加/删什么 | 按类型分层：sibling / synonym / component | 位置 5–8 上**碰巧是什么就是什么** |
| 类型效应 | sibling **−11.52pp**、synonym **+4.85pp**、component ≈ 0 | 尾部候选 P(complete) 仅 0.006–0.036 |
| 基线池 | width-4，参照已暴露 | width 8.54，参照已暴露 |

**往池里塞一个金标的近亲，和从池里删掉几个低质量尾巴，不是同一个操作的正反两面。**
`CROSS_EXPERIMENT_ROOT_CRITICAL_SYNTHESIS` §6 早就写了"有效宽度由新增候选的独有证据、
对象类型与拓扑决定，**不由槽位数决定**"。本实验从**删除方向**独立确认了后半句：
**槽位数本身不是杠杆。**

## 7. 一处口径更正：预注册的"必回归"数算的是另一个量

预注册 §3 的表写"必回归 0 / 0 / 3"，实测是 **1 / 1 / 6**。不是计算错误，是两个定义：

- 预注册那一列算的是"**池内所有**完整标签都被截断删掉"的病例数，
  它衡量的是**天花板损失**（0 / 0 / 3 正确）。
- 实测这一列算的是"**冻结冠军本人**被截断删掉"的病例数（1 / 1 / 6）。

差额来自"冻结冠军是完整的，但它排在位置 ≥N，而另一个完整标签排在 N 以内"的病例。
两个量都对，但**报告必回归时必须说清是哪一个**。天花板未受损而具体冠军被换掉的情形，
在本实验里恰好也基本无害（那 1 例即 `mcr_200b/340`）。

## 8. 限制

- **三模型盲评面板不是人工根真值**（五分类 exact accuracy 0.7082、Gwet AC1 0.6544）。
  但本报告的核心证伪证据（15/167 冠军变化、10 对不一致、50 例中 41 例冠军未变）
  **完全不经过面板**，是机械计数。
- 面板误分类对四臂非差分（判定按 `(case, label)` 冻结于本实验存在之前，不含臂身份），
  因此会把观测效应向零收缩。**这意味着不能把 Δ = −2 读成"截断确有害"**——
  可写的是"未测出任何正向效应，且系统被扰动的幅度不足以支持预测的增益"。
- 队列是"池内含完整标签"的 167 例。另外 233 例按预注册 §1 的恒等式在 clinical-complete 上
  机械固定，故主端点的全 400 率是精确的；但 **task 与 legacy 两个次端点在那 233 例上是可变的**，
  因此本报告的 task / legacy 读数只在 167 例上成立，是部分切片估计。
- `flat5` − `group5` 同时改变了分组框架与 prompt 的两步决策结构，两者不可分离（预注册 §3）。
- N = 3 / 5 是**一族、一组切片上的两个探针**，不构成任何通用宽度结论。

## 9. 对下一步的含义

**MCR 的 63 例选择损失不能靠改候选集合拿回来。** `CLINICAL_RESCORE` §5 更正后的读数 3
（"需要比较器本身改变"）原本只针对已进决赛的那一部分，现在**在全部 63 例上得到确证并推广**：
完整标签留在名单上、干扰项被删掉，比较器依然选别的，兑现率只有 8%。

因此这一层剩下的杠杆是**比较器内部**，不是名单：

- **证据整合**是已有正面先例的方向：E4 在**同一个候选池**上只换 evidence integration，
  就把 model-panel complete 从 7.75% 抬到 17.25%；E9 增加真实独有视图取得 +3.25pp
  （Holm `q = .01328`）。这两个都是"池不变、比较器变"，正是本实验证伪之后剩下的空间。
- **§4.1 那条"退向粗父类"的倾向**本身可能是一个可干预点：完整性端点惩罚粗父类，
  而 prompt 现有的家族/亚型规则在鼓励它。这需要单独预注册，且必须与本实验分开，
  因为它是**改判据**而不是改名单。
- 与此同时，**位置先验（位置 0 的 P(complete) = 0.233，是位置 1 的近 4 倍）仍未被利用**，
  而冻结设计（`selector_unanchored`）刻意不把它告诉模型。"把位置或分数写进 payload"
  是**信息注入**，与本实验的候选删除是两件事，本实验的零结果**不能**外推去否定它。

**不可以从本实验得出的结论：** 不可写成"MultiStance 的宽召回结构有害"或"应当收窄候选池"——
恰恰相反，收窄没有收益；也不可写成臂间比较（MCR 上 multistance 104 / collapse3c 107 /
forest 93，配对 McNemar 全不显著）。

## 补记（2026-08-21）：§9 三条候选杠杆的后续裁定

`MCR_SELECTION_LAYER_AUDIT`（零调用）与 `MCR_EVIDENCE_SYMMETRY_GATE_V1`（128 调用）已对
§9 列出的三条杠杆逐一定量，其中两条需要下调或更正：

- **"退向更粗的父类"（§4.1、§9 第 2 条）是小杠杆，不是主因。** 在 167 例队列上按临床关系
  分解 63 例损失：`not_equivalent` 25、`conflicting_subtype_or_scope` 17、
  `manifestation_or_related` 13、`partial_parent_or_component` 仅 **8**。主导模式是放着
  shortlist 里的精确匹配不选、去选临床上不同的同族兄弟（gold `Leiomyosarcoma` 选了
  `Malignant solitary fibrous tumor`；gold `Mucormycosis` 选了 `Blastomycosis`）。
  改家族/亚型判据最多覆盖 8/63，不应作为主线。

- **"位置先验尚未被利用"（§9 第 3 条）的表述需更正。** 该先验并非未被利用：比较器与
  payload 位置 0 的选择一致率为 **130/167 = 77.8%**，而位置 0 本身盲取即得 93/167，
  比较器 104/167——整个 LLM 比较步骤的边际价值是 **+11 例**。更关键的是，把位置换成任何
  可从冻结 payload 计算的排序都会**掉点**：生成序在 dev 与 holdout 上同时胜过 8 个替代
  排序（specificity、stance 计数、`for` 计数、`for − against` 等），因此"写进 payload 的
  信息注入"在离线信号范围内无可用增益。

- **"证据整合"（§9 第 1 条）确认为主线，且机制已定位。** 63 例损失中正确候选相对冠军
  系统性弱势（`for` 更少 48/63，均数 2.29 vs 3.84；带 `against` 42/63 vs 28/63），
  即比较器是忠实执行了一份被污染的输入。对每候选独立、对彼此盲的对称重推使该不对称
  基本消失（`for` 更少 48 → 28，均数差 1.56 → 0.59，符号检验 p = 0.0031），且收窄几乎
  全部来自**冠军一侧缩水**（3.84 → 2.81），并集中在 payload 位置 0 的冠军（Δ −1.25，
  位置 >0 仅 Δ −0.53）。stance 调用在一趟里既提候选又写证据，系统性地给它首先提出的
  候选堆砌支持 span——这同时为 77.8% 的位置顺从性提供了因果路径。

综上，本实验"剩下的杠杆在比较器内部"这一结论方向成立，但更准确的定位是**比较器上游的
逐候选证据分配**：不是比较器判断失误，而是它收到的证据带有次序性偏置。
