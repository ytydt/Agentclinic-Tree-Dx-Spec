# E12 e7 representation × width × comparator: frozen design

E12 uses the 300-case E6 relation-challenge development sample (DA 150, MCR
150). It reuses the historical e7 three-call S2 proposal multiset and never
regenerates a proposal after seeing an outcome. This makes the downstream
factorial an intervention on representation, candidate exposure and comparison
only—not a new generator comparison.

The main 3×2×3 cells are:

- representation: clean raw vignette, historical e7 S1 summary, or the frozen
  E6 typed event graph;
- width: nested k=5 or k=10 after exact/frozen-safe-synonym identity only;
- comparator: no-call historical-priority first item, one-call pointwise S4,
  or one-call pairwise contrastive selection.

k=5 is the historical S3 shortlist after safe identity deduplication. k=10
retains that set and fills from first-occurrence unused S2 proposals. Candidate
IDs and payload order are case/concept-SHA frozen and shared across all three
representations; gold, options, historical rank/source, old champion, vote and
score are withheld. Pointwise and pairwise receive the same candidate payload.

The secondary call-depth path holds raw representation, k=10 and pairwise
selection fixed while cumulatively admitting S2 call 1, calls 1+2 and calls
1+2+3. Depth 3 reuses the main `raw_k10_pairwise` cell. Delta-U accounting
separates unique candidate additions, strict reference exposure, cap
displacement, paired rescue/harm and runtime cost. Historical S2 has labels but
not a shared evidence-first ledger, so evidence novelty is explicitly
unidentified rather than guessed.

Strict exact-or-frozen-safe-synonym pre-mapper Top-1 is primary. Clinical
complete equivalence, partial/scope sensitivity, candidate deletion and
trajectory mechanisms require a separately frozen heterogeneous screen plus
root audit. E6 graph-construction failures fail closed in graph-using online
cells and remain in intention-to-analyse; the first-item negative control does
not consume the graph and therefore remains defined.

This is a development mechanism experiment. Repeat runs, a new confirmation
set and provider/retry standardisation remain excluded as variance-only arms.
