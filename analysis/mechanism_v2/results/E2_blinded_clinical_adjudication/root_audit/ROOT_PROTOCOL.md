# E2 root audit protocol

The root auditor reads `identity_cards.jsonl` and `relation_cards.jsonl` without the index files. Decisions are frozen as compact codes before arm provenance, strict correctness, mapper outcomes, sampling strata or queue reasons are joined. Safe frozen exact identity may be accepted deterministically; substring containment is never identity.

Every reviewer identity disagreement/failure, every complete or complete+partial boundary disagreement, every non-identity consensus complete, and frozen consensus calibration samples are reviewed. Unreviewed exact reviewer agreement keeps explicit consensus provenance; unreviewed non-endpoint disagreements resolve to uncertain.
