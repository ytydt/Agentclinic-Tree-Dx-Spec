# 机械规则链实现缺陷审计：代码修复、语义恢复与设计政策的边界

日期：2026-09-08。输入版本：`cursor4@bbc036e8a6ec93583be915a4609fe86278ed062c`。本轮首先同步并核对远端，未发现上一交付后的新增提交。**本任务交付审计、反例和修复方案；生产代码未修改，未重新请求 LLM，未声称修复后临床性能已获提升。**

## 1. 结论与对问题前提的校正

现有机械链确实有大量可以先于算法重设计修复的实现缺陷。病例56中正确疾病主语被父类抢走，至少有一个直接原因是候选循环的提前 `break`，不需要换模型才能修正。组成员丢失、首行阈值与后行模态拼接、相同配置名继承上次运行状态、缓存/产物键缺信息，也属于可确定性定位的工程问题。

但“规则匹配到错误疾病”不是一个单一 bug：原文主体抽错、候选 alias 污染、正确主体路由错、父子关系误作等价、一般父类证据被当作亚型特异判据，分别发生在不同阶段。代码可以阻止无许可的转换，不能从已经丢失的语义中自动恢复所有正确连接。本文将**防止错误的确定性约束**与**恢复合法匹配所需的语义能力**分开。

另有四项必须准确表述：

1. 这些问题多数已经是旧 redesign 的明确目标，尚未落实到生产实现。不能把未实现误写成未设计。本轮新增的是更具体的故障位点、实际函数反例、迁移验收，以及若干旧表未列出的辅助路径缺陷。详见 [旧设计覆盖核对](PRIOR_COVERAGE_REVIEW.md)。
2. 去重后并不是保存了显式 `null` 成员。现行算法先删除重复 occurrence，再从剩余代表行重建组；组会缩小，少于两行时被删除，剩余原子重新进入原子执行路径。修复要恢复 **member edge**，不是给空字符串做替换。
3. 组键已有归一化主语。因此并非任意不同主语只要同名 `g1` 就直接合并；实际碰撞涉及绑定候选、归一化主语、标题/章节/focus/local ID 相同而真实源窗不同，或主语已在上游被破坏。根本缺少的是可靠源规则身份与组完整性。
4. 现行 `context_type`、`SOFT_CONTEXTS` 和部分 gate 已区别 treatment 等上下文，不能说完全没有阶段处理；但这些粗标签没有形成端到端的阶段/意图/对象/事件状态合同。仓库另有类型化 KG schema，不能将机械链的缺陷外推为全仓没有递归组或人口范围。

## 3. 用户列举的问题，实际在哪里发生

| 问题 | 代码机制 | 可立即做的代码修复 | 仍需恢复的语义 |
|---|---|---|---|
| 正确规则跑到无关主语 | `run_case` 首次 subject_match 即退出；对称 containment、破坏性 norm、未经验证的 alias | 全局比较身份；可信 exact 优先；保留 raw；不明身份弃权并记录 | 原文真正主语、同义/多义、父子/组件/病因关系，及允许的继承方向 |
| 不同源规则的组碰撞 | `_title/_section/_focus/gid/norm(subject)` 没有实际源窗口/提取活动身份 | 源规则 ID 与 occurrence ID 分开；校验组目标/结构一致性 | 多窗口是否属于同一源标准、指代和跨段组边界 |
| 去重造成成员缺失 | 原子代表去重先于完整组；小组被删除并回落原子执行 | 先构建规则与成员引用，再做叶定义共享；不删 edge、不悄悄回落 | 自由改写是否真正等价；被丢掉的旧组边界需回源恢复 |
| 去重不足与过度同时存在 | key 只含 predicate/relation/polarity；不同阈值会合并，不同措辞会多票 | 完整类型化 key、稳定来源身份、保留冲突与多时点 | 语义同义、逻辑等价与来源独立性，不能靠通用相似度阈值 |
| 竞争句数量变定向反证 | L4 每条有 comparator 且 finding present 的句子固定扣 .5；未核验方向/上下文/组根 | 非合格比较不能进入 L4；完整比较对象、根证明、重复证据一次记账 | 到底 favors 谁、比较条件是否满足、候选是否可共存、原文是否只是 DDx 列举 |

**L4 并不实现正式的“反证证明计数”。** 它实现的是按满足若干弱条件的行重复扣固定分。把该分数解释为定向反证强度，超出了实际代码和来源所支持的意义。纯代码可去掉重复计账和无资格通路；恢复正确比较需要 `target_a/target_b/condition/favors/scope/proof`，而不是把全部竞争句去重后继续扣分。

## 4. 实现缺陷如何串联破坏正确结果

### 4.1 身份错误先污染候选，再污染计分分母

病例56中，完整 Sarcomatoid SCC 的同名原始主语已存在，但父类 Carcinoma 在候选顺序中先截获它。原报告的四臂完整标签均无绑定断言；对已有行作明确路由后，完整标签排名变为 3/3/5/5。这是已有信息没有被正确使用，不能只归因为 LLM 缺医学知识。该干预也不证明所有被路由行都已忠实、正确地连接患者证据。[病例56](../V2_INDEX_DIFFERENTIAL_AUDIT/cases/case_56.md)。

错误行即使最后不直接计分，仍可能先进入 `claimants`。来源无关的 epidemiology/treatment 行、阈值不合格行或后来已排除的候选，可以改变别的候选的正向权重。病例49的零分 TB 比例误接血中 neutrophils 就展示了这种隐藏通路。[病例49](../V2_INDEX_DIFFERENTIAL_AUDIT/cases/case_49.md)。所以只检查最终贡献列表或删去其数值 delta，不能完整修复。

### 4.2 原子共享被实现成删除来源，组语义随后变形

当前去重不仅删除重复票，还删除后续 occurrence 的组归属、阈值、比较对象和来源上下文；代表行可保留旧 quote/threshold，却吸收其他行较强 modality。这会生成没有任何单一源句真正支持的混合对象。

随后组装只看到幸存行。相同标题/focus/local ID 的不同源窗可能拼成一组；同一个真实组也可能只剩一个成员，继而以独立原子的身份触发 L1/L2。已成组者则按 finding 的 present/absent 直接计 sat/vio，而未完整读取成员极性、数值比较和根效果。因此“源提得更完整”不保证“可执行规则更完整”：输入增加可能同时增加碰撞、模态拼接、重复见证和非诊断上下文影响。[组专项分析](engine_structures.md)。

### 4.3 相似度与字段遗漏把不同事件压成一个事实

这里不是仅有阈值高低问题。`predicate_kind`、finding 的 `kind/site/timing` 等已有字段没有成为连接约束；`value.text` 的病原体又可能完全不进入匹配。数值比较的单位缺失、单位大小写、非有限值与范围上端异常还有确定性边界缺陷。

同一个 finding 先用 canonical 弱命中便停止比较其 label，导致已在数据中的 exact 信息失效；同等级匹配的相反时点事实又由数组顺序决定。扩大 embedding 召回可能扩大错误连接，关闭它也会丢掉合法别名；两者都不能代替事件身份、参数及类型检查。[身份分项](semantic_identity.md)。

### 4.4 无方向比较与配置/缓存错误使修复效果也可能被误测

除了 L4 把 DDx 行当定向扣分，辅助 corpus lift 的病例相对统计还被写入不含病例候选集的键；合成真实 main 反例显示，仅交换病例顺序，Alpha/marker 的最终 lift 就从 .0606 变为 .5306。`configure` 的不完整复位、配置未进入输出路径，以及提取缓存漏掉真实 prompt/parser 等，则可能使“改了算法”的实验读取旧结果或覆盖其他结果。[辅助完整性](auxiliary_integrity.md)、[上游完整性](upstream_integrity.md)。

这些是工程与测量风险，不自动等于历史 11 例曾发生该污染。上一轮精确重放独立冻结了配置和输入，其结果不因本轮发现可选路径缺陷而失效。

## 5. 修复应分三层推进

### A. 不等待新模型的代码修改

先保护已有信息和实验可信度：不可变完整配置；内容寻址缓存与原子写入；成功空提取/失败/截断分态；源窗口和 raw output 版本；全局可信 exact 搜索；全部 finding 表述比较；数值类型与有限性校验；组成员引用与稳定命名空间；不跨来源拼接模态；准入先于 claimants/L4；死开关和产物覆盖修复。

这些改动的目标是输入不变时满足明确不变量，不应先以 MRR 是否上涨决定要不要修。错误抵消曾帮助旧 top-3，因此单项正确修复可能使代理指标下降；要同时看规范正确性、完整标签/父类终点及错误动作。[上一轮新旧差量结论](../V2_INDEX_DIFFERENTIAL_AUDIT/REPORT.md)。

### B. 先定合同，再写执行代码

`argues_against` 是否能硬排、all 是否意味着必要、源不完整时如何求值、不同上下文能否共享权重、何种比较可扣分，都不是随意改一条 if 就有唯一答案。应先采用明确的根效果、三值/冲突、许可和阶段/范围合同，再编写执行器。详见 [补充任务主报告](../RULE_STAGE_SCOPE_SUPPLEMENT/REPORT.md)。

修复组引用并不要求立即上线一个通用 FOL 系统；可以先支持经核验的浅层子集，把不支持的递归结构保留为 unsupported，而非拆成独立硬原子。反之，给旧行统一补 AND、TRUE scope 或 diagnosis stage 会继续虚构语义。

### C. 用额外语义能力恢复合法覆盖

优先复用仓内 KG 的 ID、ConceptMapping、FeaturePattern、LogicExpression 和引用校验，再接版本化术语/本体。BioSyn、SapBERT 等可用于候选召回，但输出相似度不是医学等价或执行许可；上下文、概念类型、限定、范围和关系方向须另行核验。检查/程序的规则允许无疾病目标，不能通过“找最近疾病”强补主语。

针对未解析部分采用有限候选、源跨度、关系类别与弃权的验证任务，避免自由改写主语。词面相同也可能多义；没有词面重叠也可能是安全别名。研究设计需同时保留正反控制，如 CD31/PECAM-1 可桥接，但同 marker 的正负结果不可同值；可信 exact 子类应取回自己的规则，合法父类必要条件仍可有来源地继承。[技术调研与实施方案](semantic_binding_research.md)。

实体链接不能解决全部混合缺陷。[六类技术覆盖矩阵](SEMANTIC_REPAIR_MATRIX.md)将27项逐一映射到概念主体、观察/数值依附、命题等价、源文方向/作用域、定向比较、阶段与源单元完整性。它另核验 ConText/medspaCy 的范围化临床上下文处理，并复用上一轮组合FOL/受控语言研究；各方法的可用能力、不能保证的内容及下一步对照都分别列出。

## 6. 修复与研究的验收顺序

详细工作包见 [REPAIR_PLAN.md](REPAIR_PLAN.md)。建议分开交付、逐层冻结：

1. **运行与来源完整性**：先保证实验真的读取新配置、新来源与正确缓存，失败不冒充空提取。
2. **身份与引用完整性**：保持原始字段、组 edge、来源 occurrence；消除顺序抢占、重复对象及无信息降格。
3. **类型与动作准入**：已有类型字段参与连接；同一 guard/effect/目标合同贯穿组、原子、claimants、L4。
4. **已解析子集的确定性执行**：完整组与原子获得一致求值，重复曝光不新增票，未知/无效数值不成为硬反例。
5. **语义恢复试验**：在固定源、候选和事实下测量合法绑定/错误绑定/弃权，随后才加入自动事实抽取与端到端排名。

需要的验收不是只有回归 top-3：还包括输入排列不变性、重复曝光不变性、无关候选不污染已合格证据、组引用完整性、类型/单位/时点反例、缓存隔离、来源保真和硬动作权限。某些算法明确依赖候选集的排序量可以改变，但必须在声明的接口中变化，不能由不合格或零分行暗中改变其他项。

## 7. 已验证与尚未验证

四个复现脚本直接调用冻结生产函数或在隔离临时输入中运行真实入口；网络传输按需替换为明确的测试响应。静态边界项与实际执行反例在各记录中分开。脚本通过证明的是所描述的旧行为可复现；未将断言方向反过来写成“bug 已修”。统一 [delivery_validation.json](delivery_validation.json)记录实际通过数与源哈希。

| 检验空间 | 实际完成 | 计数的含义 |
|---|---:|---|
| 身份/事实 | 23 项技术检查 | 含显式负控制及成对机制组成检查，不是 23 个错误输出 |
| 执行器 | 34 个有限见证；读取 44 个历史包 | 含正确行为控制；历史部分是结构普查 |

独立复核实际排除了一项初稿假阳性：单独 `--nli` 会经 `FIX_QUOTE_GATE or FIX_NLI` 调用 gate；该指控已从清单删除，改为正确行为控制。审计也修正了将单位别名等价误写为错误、以及将成对检查的正确一端计作独立错误的措辞。复核关闭记录见 [INDEPENDENT_REVIEW.md](INDEPENDENT_REVIEW.md)。

新增历史机械观察包括：四臂全部属于 SOFT_CONTEXTS 却仍实际计分的组为 **27/20/33/24**，从已成组叶子直接发出的 L4 处罚为 **5/5/21/32**。这些显示不同消费者的准入合同不一致；**不等于每一次都是已人工裁定的错误诊断**，也不能把计数当作 MRR 损失分摊。

历史结构普查来自已有 44 个重放包及提取文件。组缩小、不同槽位被合并、跨 cache 组等统计是**结构标记**，不把全部次数都裁定为独立医学错误；例如两个不同 raw subjects 可能本来是同义名。同样，corpus lift 的 5 个跨病例共享查询键只说明潜在入口，没有被解释为 5 个已证实的历史覆盖错误。

本轮没有运行新的医学抽取、全量语料重建或修复后 11/800 例性能实验；没有下载 LFS 大对象。文献方法和参考型合同也没有直接部署。下一轮应实施明确工作包并分别检验工程不变量、语义恢复和临床终点，不能把本报告的“可修复”读作“已经修复”。
