# 这个目录在讲什么（面向初次阅读者）

共用术语见 [../READER_GUIDE.md](../READER_GUIDE.md)。本文只讲这个目录独有的东西。

## 一句话

前面几份审计说「语义被扭曲了」，容易让人以为**必须换更强的模型**才能解决。这个目录的核心论点是：**其中相当一部分是普通的程序 bug，现在就能修，不用等新模型。**

它把问题分成三类：

| 类别 | 数量 | 含义 |
|---|---:|---|
| `code_only` | **29** | 纯代码缺陷，改代码即可 |
| `hybrid_semantic` | **27** | 代码能挡住错误，但要恢复正确答案还需要语义能力 |
| `design_policy` | **7** | 得先定政策才能写代码（例如「`argues_against` 到底能不能硬排除」）|

合计 **63 个工作项**。注意这是**工程工作单元**，不是 63 个独立的临床错误。

## 一个说明问题的例子：例 56

金标是「梭形细胞鳞状细胞癌」。候选池里**本来就有**这个完整标签，但它排在第 21 名，而泛化的父类 `Carcinoma` 排第 6。

原因很朴素：`run_case` 把断言绑定到候选时，**匹配到第一个就 `break` 了**。父类 `Carcinoma` 在候选顺序里排在前面，于是把本该属于亚型的证据全都截走了。

把这些行明确路由到正确标签后，完整标签的排名变成 3/3/5/5。

**这不需要模型更懂医学——是已有的信息没被正确使用。**（但审计也声明：这次干预不证明被路由的那些行本身都是忠实正确的。）

## 需要解释的专用说法

| 说法 | 平实解释 |
|---|---|
| **semantic identity（语义身份）** | 「这条规则到底在说哪个病、哪个检查、哪个时间点的哪次观察」。大量错误是身份没对上，不是逻辑算错。 |
| **claimants** | 引擎内部的一张表：某个病人发现，被哪些候选诊断「声称」过。它用来算「这个发现有多特异」。**问题在于**：不合格的行、零分的行、甚至后来被淘汰的候选，都可能先混进这张表，从而**暗中改变别的候选的分数**。 |
| **L4 竞争扣分** | 层四会给「带比较词、且对应发现存在」的行**固定扣 0.5 分**。审计指出：这**不是**真正的「定向反证计数」——代码没有核验这句话到底在支持谁、比较条件成不成立。把这个分数解释成「反证强度」超出了代码实际做的事。 |
| **模态拼接（modality splicing）** | 去重时，保留下来的那一行会**吸收**被删掉那些行里更强的语气。结果可能产生一个**没有任何单一原文句子真正支持**的混合对象。 |
| **组 edge（成员边）** | 「这条断言属于哪个组」这层关系。审计特别澄清：现在的去重**不是**保留了一个空成员，而是**先删重复行、再从剩下的代表行重建组**；组因此缩小，少于两个成员就被整个删掉，剩下的原子又回到单条执行路径。所以修复要恢复的是**成员边**，不是给空字符串做替换。 |
| **prior coverage（旧设计覆盖）** | 这些问题**大部分早就在旧的重设计方案里提过了，只是没落实到生产代码**。审计强调不能把「没实现」写成「没设计」。 |
| **negative control（负控制）** | 检查清单里故意放的「正确行为」样例，用来证明检查器不是见什么都报错。 |

## 一个被独立复核推翻的初稿指控（值得注意）

初稿曾指控「单独开 `--nli` 不会调用门闸」。复核发现代码是 `FIX_QUOTE_GATE or FIX_NLI`，**会**调用。该指控已从清单删除，改成一条正确行为的对照。审计还更正了把单位别名等价误写成错误、以及把成对检查里正确的那一端计成独立错误的措辞。

## 读结论时的边界

- **「可复现旧行为」≠「已修复」。** 复现脚本跑通，意思是缺陷仍然存在。
- 反例数量**不等于** bug 数量，也不等于临床错误数量。
- 部分缺陷位于**可选路径**（例如 F8、grounded backfill），它们**不能**追加为冻结四臂排名下降的原因。
- 「四个臂里属于软上下文却仍然计分的组是 27/20/33/24」「从已成组叶子直接发出的 L4 扣分是 5/5/21/32」——这些是**结构标记**，说明不同消费者的准入合同不一致，**不等于每一次都是已裁定的诊断错误**。
- 本轮**没有**跑修复后的性能实验。

## 修复的推荐顺序（这是它给下游最有用的东西）

1. **运行与来源完整性**——先保证实验真的读到了新配置、新语料、正确缓存，失败不要伪装成「抽取为空」。
2. **身份与引用完整性**——保住原始字段、组成员边、来源出处；消除「先到先得」的抢占。
3. **类型与动作准入**——已有的类型字段要真的参与判断；同一套许可贯穿组、原子、claimants 和 L4。
4. **已解析子集的确定性执行**——重复曝光不新增票，未知/无效数值不能当硬反例。
5. **语义恢复试验**——在固定输入下测「合法绑定 / 错误绑定 / 主动弃权」三个量。

审计特别提醒：**不要用 MRR 涨不涨来决定要不要修第 1–4 步**。错误抵消曾经帮助过旧的 top-3，所以一次正确的修复完全可能让代理指标**下降**。
