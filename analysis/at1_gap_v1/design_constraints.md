# 阶段 4：设计约束定稿（design_constraints）

## 1. 问题陈述（冻结）

本方法 option **@2/MRR 领先**，**@1 略低于** MAC/DualInf；转化效率 P(@1|@2)=0.756 ≪ MAC 0.910。主分析队列 A=19。

## 2. 硬护栏（验收可测）

| ID | 约束 | 验收 |
|----|------|------|
| G1 | 候选封闭：只重排 joint 已产出 Top-K 叶 | 代码审查 + 无开放 vignette 主列表 |
| G2 | Top2 **集合**单调：校准后不得丢掉校准前 Top2 中任一已映射命中 gold 的叶（允许交换） | 离线模拟 Δ@2≥0（点估计） |
| G3 | 指标护栏：烟测/全量以 option **@2、MRR** 为护栏，@1 为主优化 | 任一支路 @2 明显下降 → 否决 |
| G4 | 粒度支线隔离：Fine/Coarse 不得假装单靠打分根治 | 消融分列报告 |

## 3. 数据驱动阈值（本轮）

| 信号 | 观测 | 约束 |
|------|------|------|
| Fine 主模式 | 8/19（42%） | 方案 **必须**含 `AdaptiveMergeSiblings` |
| Coarse Agent 通过 | 7/19（37%） | 方案 **必须**含 `AdaptiveSubdivideUnderL2`；**禁止** support 重排作唯一对策 |
| 纯排序 | 1/19（5%） | `TopKCalibration` 仅声称修复此类 + 作为 Fine/Coarse 的辅助 |
| L2 vs L1（A 集） | L1-prior 虚拟 @1≈0.63；L2 叶序伤害首位 | 校准模块须可 **fallback L1 序** |
| Mapper 模式 | 本方法 `typed_llm` vs 基线 `typed_llm_disagreement_rag` | 跨系统 Δ@1 不得写成无混杂硬宣称 |

## 4. 2×2 提醒（防过拟合基线）

- 本方法独占 @1：19；MAC 独占：21；Dual 独占：20。  
- 集合 C（本方法中、两基线皆否）=13 → 任何融合不得系统性毁掉这些例的 Top2。

## 5. 明确不做

- 不立即改生产 joint/建树代码或开全量实验（本阶段设计）。  
- 不把 MAC 整段多医生讨论嵌进建树主路径。  
- 不以牺牲 @2 换取与基线同质的开放生成 Top1。
