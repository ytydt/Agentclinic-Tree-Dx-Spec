## 3. 注册目标未达成，且**结构上达不成**

R1h 登记的扩样目的是让 AB10/AB10b/AB11「进入可判决区」。合并后 p 分别为 0.125 / — / 0.250，**未进入**。原因是结构性的：

- 这些臂的不一致对**全部单向**（c=0）。c=0 时精确条件二项双侧 p = 2^(1−b)，故 α=0.05 需 **b ≥ 6**；
- 合并后 b 为 AB10 = 4、AB11 = 3；即便切片二补齐到 n≈100，按当前率外推 b 约 5–6，**最好落在 p≈0.03–0.06 的边缘**；
- **AB10b / AB10c 在两个切片上不一致对均恰为 0**，任何样本量都无法移动——这是结构恒等，不是功效问题。

## 4. 利弊判断（回答"不确定其利弊"）

**注册目标与现行叙事方向相反，这是核心。** R1h 已把块 2 从"提准确率"重定位为**正向等价**主张（"实现无关，界 ≤3pp"）。在这个框架下：

- 扩样使等价界**更紧**（多数臂上界由 ~3pp 降到 ~2pp）⇒ **有利**；
- 若扩样真让 AB10/AB11 显著，反而**证伪**"实现无关"这条正在主张的结论 ⇒ 未达可判决区对现行叙事是**好事**。

⇒ 就块 2 而言，**扩样是净有利的，且正因为它没有达成当初注册的那个目标。**

**代价在 MCR 头条，不在消融。** 若合并进正文：

|---|---|---|---|

**一条硬约束：现在不能只并一半。** 摘要与 §消融的承重数字「联合拆除 0.50 → 0.42」（15 检验中唯一过 Holm 者）的切片二数据**尚未产出**（52/100）。若把头条改成 n=200 而这条仍是 n=100，同一段内会出现口径不一致，是审稿人必抓的破口。
