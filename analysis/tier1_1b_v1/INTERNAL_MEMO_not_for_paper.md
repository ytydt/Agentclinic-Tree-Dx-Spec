判据：主文（`paper_aaai/main.tex`）已提交锁死不可改。任何在字面上或在读者可直接推演的层面上**否决主文已刊论断**的新证据，

## 1. 写回负控臂的点估计（否决风险：最高）

OX 锁定预算下六臂 micro-F1（`analysis/tier1_1b_v1/t107_writeback_factor.json`）：

| 内部代号 | 写回处理 | micro-F1 |
|---|---|---:|
| M00 hot（已刊） | normal | 0.6508 |
| AB13 cold（已刊） | off | 0.5759 |
| STF_normal | 同配置复跑 | 0.6384 |
| AB29 placebo | cap 用新分、落盘恢复旧分 | 0.6605 |
| AB30 shuffled | 叶↔分打乱（保留分数多重集） | 0.6784 |
| AB31 flat | normal + 全局单一 scope | 0.6425 |

**为什么不能入论文**：AB30（打乱叶与其自身更新分的对应）为 0.678，**高于**已刊部署臂 0.651。
按字面读，这否决主文反复使用的 "evidence-conditioned" 这一限定词（主文 §RQ3、Contributions、Conclusion 均依赖它）。

**为什么也不能反过来当作结论**：同配置复跑（STF_normal）在**不改任何配置**的情况下就偏移 0.0124，
且逐叶后验仅 4/100 复现（见 §4）。臂间最大差 0.040、AB30−M00 = 0.027，均与再执行噪声同量级；
n=100 且无重复复跑 ⇒ 无方差估计 ⇒ 这些臂之间**不可判定**。

**结论**：既不写"机制被否决"，也不写"机制被证实"。补充材料只保留 §4 的复现带（同向、加严），
把细分归因作为 open question 前瞻性表述。后续需要：确定性 annotate 重放 + ≥300 例确认集 + 每臂 ≥3 次复跑。

## 2. MCR 切片二符号反转（否决风险：高）

`analysis/tier1_1a_v1/case_bootstrap.md`：joint-off 对照（M00 − AB04，Acc@1）

- 切片一（已刊的 n=98 配对）：Δ = +0.112，percentile CI [0.051, 0.173]，sign-test p = 0.001
- 独立切片二：Δ = **−0.040**，p = 0.45

**为什么不能入论文**：主文唯一通过 Holm 的等价性消融就是这一条（0.50 → 0.42）。
在补充材料写出"独立切片上符号反转"等于自证不可推广，直接否决已锁定的确证性论断。

**为什么不构成隐瞒**：主文 Future work 已明写 "extend the mechanism tests to independently sampled and
full-benchmark evaluations"，即已把外推性列为未完成事项。补充材料对切片一的复算与已刊区间一致，无矛盾陈述。

**后续**：切片二应作为确认集的预注册对象，而非本轮的报告项。

## 3. 结构归因（T1-08）（否决风险：高，且方向与预期相反）

`analysis/tier1_1b_v1/t108_summary.json`，DA，统一 open lexical@0.7 对自由文本 gold：

| 配置 | Top-1（同一判据） |
|---|---:|
| 十轨迹离线 RRF 融合 | 0.32 |
| 十轨迹并集池 → 部署仲裁模块 | 0.41（schema valid 100/100） |
| 最强扁平检索基线池 → 部署仲裁模块 | 0.41（schema valid 97/100） |
| **部署系统自身（本轮补测）** | **0.439（43/98）** |

本轮补测方法：取 `pilot24_compat_b12_live_v1` + `remain76_compat_b12_live_v1` 的
`l2.final_ranking_labels[0]`，用同一 `leaf_match_score ≥ 0.7` 判据对同一 gold 打分。

**为什么不能入论文**：在这一自由文本判据下，把扁平池喂给**同一个**仲裁模块即可达到 0.41，
与部署系统 0.439 仅差 0.03。这与"组织与状态承担了主要边际"的叙事**方向相反**，
会被审稿人直接用来质疑 organization 论断。若只报 0.32 → 0.41 而隐去 0.439，属选择性呈现，同样不可接受。

补充说明（不改变结论）：主文 DA Top-1 = 0.71 是**选项端点**，与此处自由文本判据不是同一标度；
但 0.41 与 0.439 之间是同标度比较，问题真实存在。

**另一条同样不入论文的数字**：`flat_stateful_ab02` 选项 Top-1 = 0.68 vs 部署 0.71。
读者可据此算出"完全去掉 L1 轴只损失 0.03"，与主文轴对照（0.71 vs 随机轴 0.37，+0.34）并置会产生张力。
机制上二者可调和（随机轴的损失主要来自它诱发的选择器弃权，见补充材料 Axis Cascade 表：随机轴 97/100 零选择、45 例空排序），
但主文已把该对照限定为 "pipeline effect"，本轮不宜再引入会促使读者重算轴贡献的数字。

## 6. 槽位效率与准确率跨系统无关（否决风险：中；原为拟画的 F6）

数据取自补充材料 `tab:slots-cross`（OX 上统一词面判据的各系统发射列表浪费率）与 `tab:all-baselines`（OX micro-F1）：

| 相关性 | Pearson | Spearman |
|---|---:|---:|
| 仅 14 条基线 | **+0.173** | +0.288 |
| 含主方法 | **−0.170** | +0.046 |

即：跨系统看，"槽位浪费率低"并不预测"micro-F1 高"，在基线内部符号甚至相反。

**为什么不能入论文**：原可视化建议是"若跨系统呈单调关系，这是不依赖任何消融的机制证据"。前提不成立，照原案画散点等于用一张图自证槽位效率这个机制指标不预测端点表现，会被直接用来质疑"概念级竞争"这条机制。

**可用的替代**：补充材料自身的论证本就不是跨系统单调，而是**系统内前后对照**——扁平系统的发射列表本来就分散（0.033–0.098），冗余是我们自己的组织方式造成的（窗口 0.643），压缩把它降到 0.029 低于所有扁平系统。已据此绘制 Figure 3，无需跨系统相关性。

## 7. 九次调用结构代理的 token 重建（从补充材料删除）

原补充材料 §"Output tokens and latency" 末句写道：早期针对九次调用结构代理的重建报告了更大的 token 比值，该臂是推理量阶梯的低端锚点而非相似调用次数对照组，两者不可比。

**为什么删**：这个"早期重建"的数值在主文和补充材料中都不存在，主文只在资源一节写明 token/latency/成本属于未来的资源审计维度。也就是说，读者根本看不到任何与 1.14–1.28 冲突的比值，这句话是在替一个不可见的差异辩护，反而主动向审稿人植入"换一种口径这套系统贵得多"的联想，属于纯粹的自伤式过度防御。删除不构成隐瞒——没有任何已发表数字需要与之对账。

内部留档：该重建针对的是九次调用结构代理臂，位于推理量阶梯低端，与相似调用次数对照组不是同一对照，任何后续引用都必须标明对照对象。
