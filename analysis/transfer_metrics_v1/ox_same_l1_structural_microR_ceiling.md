状态：理论上界（what-if）  
日期：2026-07-26  
口径：`ox_seq100` / `official_eval` lexical；金标总数 **469**（与主表一致）  
约束假设：**每个 L1 组最多命中 1 个冠军金标**；同轴其余金标视为结构性不可恢复  
归轴：命中叶→父轴，否则强 L1 匹配；`unassigned` 各算独立 singleton 冠军

## 主结果

| 量 | 值 |
|----|---:|
| 金标总数 \(G\) | 469 |
| L1 组内冠军数（可恢复上界 TP） | **337** = 250 singleton + 87 multi-L1 冠军 |
| 同轴盈余（不可恢复） | **132** |
| **micro-R 上界**（全部冠军 hit） | **0.719**（337/469） |
| **结构性不可恢复对 micro-R 的损失** | **0.281**（132/469，约 **−28.1 pp**） |
| 当前 lexical micro-R | 0.473（222/469） |
| 当前→该上界仍可挖 | +0.245（冠军未全中的部分） |

即：在「每 L1 只认 1 个冠军」的硬约束下，**即使组内冠军全中，micro-R 也到不了 1.0，理论上限 0.72，相对完美召回永久丢掉约 28 pp**。

## 与「实测结构性缺叶」的区分

| 视角 | micro-R 影响 |
|------|-------------:|
| **What-if：强制 1-冠军/L1**（本文） | **−28.1 pp** 不可恢复 |
| **实测：同轴多金标却缺叶**（上一审计） | **≈0**（87 组里 86 全覆盖；部分覆盖仅 1 组） |

建树期 shared_trees **经常已在同轴并列多个金标叶**；28 pp 是「若系统/评测只允许每轴计 1 个命中」的理论天花板损失，**不是**当前树已经挤兑掉的实测损失。

## 构成直觉

- multi-L1 组 **87** 个 → 贡献 87 个冠军 + **132** 个盈余  
- 组规模：2×66、3×22?（见 json `group_size_hist`：2:66, 3:29, 4:15, 5:2 为桶计数）  
- 盈余占当前 FN（247）的 **53%**——若误把「每轴一命中」当成协议，会把大半 residual 错判成不可救。

## 一句话

**理论不可恢复质量 = 132/469 ≈ 28.1 pp micro-R**（上界 R=0.719）；这是 1-冠军/L1 假设下的上限损失。实测同轴结构性缺叶对 R 的影响可忽略，二者不要混用。
