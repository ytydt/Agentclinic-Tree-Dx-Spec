# OX：同 L1 多金标与结构性覆盖不全

状态：定量审计  
日期：2026-07-26  
范围：`ox_seq100` × `compat_synonym_v1`（金标=`official_eval` `gold_ddx_labels`）  
叶宇宙：`annotate/shared_trees`（与开放 posterior 评测一致）  
机器表：`ox_same_l1_multi_gold_structural.json`

## 定义

| 术语 | 定义 |
|------|------|
| 同 L1 多金标 | ≥2 个金标归到同一 L1（优先：命中叶→父轴；否则强 L1 匹配） |
| 结构性部分覆盖 | 同 L1 多金标，且该轴下 **至少 1 个金标没有对应叶** |
| 结构性多重未覆盖 | 同 L1 上 **≥2 个金标**都无叶 |

## 主结果

| 指标 | 数量 |
|------|-----:|
| 总病例 | 100 |
| 存在「同 L1 多金标」的病例 | **75** |
| 同 L1 多金标组（轴级） | **87** |
| 其中 **全部有叶覆盖** | **86**（98.9%） |
| 其中 **结构性部分覆盖** | **1**（病例 **1**） |
| 其中 **同轴 ≥2 金标均无叶** | **0** |

**结论：同 L1 下挂多个金标很常见（75/100 例），但由此导致的「结构性覆盖不全」极少（仅 1 组 / 1 例）；几乎不见「同轴多个金标同时缺叶」。**

### 唯一部分覆盖例

- case `39` L1 `B3` Vascular Disease: ✓ Essential tremor, ✗ Cerebrovascular disease


## 与 C 类缺叶的关系

| 指标 | 数量 |
|------|-----:|
| 一案 ≥2 条 C-miss | **27** |
| 其中弱匹配到 **同一 L1** | **0** |
| 弱匹配到 **不同 L1** | **0** |
| 难以归轴 | **27** |

多条 C-miss 同案 **并不等于**「同轴结构性挤兑」：它们多数 **各自无叶、且归不到同一清晰 L1**（跨轴 / 不可叶化 / 假 C），不是 parent leaf-cap 把同轴第二金标挤掉的主图景。

## 解读

1. **存在**同 L1 多金标例子，且数量多（组数 87）。  
2. **几乎都覆盖完全**——说明建树期 L2 在同轴上常能并列多个相关叶。  
3. **结构性覆盖不全不是 C 类主因**；C 更符合跨轴缺叶 / LLM 未兑现 / 评测叶宇宙错位（见 `ox_c_leaf_absent_rootcause.md`）。  
4. 若担心 Config A 的 per-parent cap，需落盘 Config A 终态树后再做同口径统计（当前短 ranking 不能当全叶）。
